# 「全部ていねいにやってもSになる」の正体

> 「時間を超過してもペナルティがない。全部丁寧にやってしまう。
>  結果Sランクになるが、どーなのだろう」

調べました。**ペナルティはあります。**ただし、お気づきのとおり効いていません。
そして、**もっと大きな問題が二つ別にありました。**
**①②③と、途中で見つかった④、すべて入れました**（下の「4. 入れたもの」を参照）。

---

## 1. 納期を過ぎると、何が起きているか

ちゃんと二つ起きています。

| | 期日内 | 遅れ |
|---|---|---|
| **売値の倍率** | ×1.10 | **×0.80** |
| **会心（S・Aのとき）** | つく | **つかない** |

売値の差は、**平均 6,021円**（売値の約27%）。ドクロのキャビネットなら **12,150円** の差です。

そして**会心を逃すほうが、じつは重い**。会心は

- **章の解放**の鍵
- **黄金の名匠／黄金の大匠／祝祭の伝説**の条件

になっています。遅れた家具は、どんなに良くても会心になりません。

### なぜ「ない」と感じるのか

**どこにも出ていないからです。**

- 期日内に間に合うと「　期日内じゃ！」と出る
- **遅れたときは、何も出ない**
- 会心を逃したことも、どこにも書かれない

つまり「良いことが起きなかった」だけで、**「悪いことが起きた」が一度も見えません。**

### それでも、お金の計算は合っています

| | 倍率 |
|---|---|
| 遅れて S | 1.5 × 0.8 = **1.20** |
| 期日内に A | 1.2 × 1.1 = **1.32** |
| 期日内に S | 1.5 × 1.1 = **1.65** |

**遅れたSより、間に合ったAのほうが高く売れます。**
設計としては正しく、効いていないのは**見せかた**だけ、のはずでした。

## 2. ところが、本丸は別にありました

### 土台が、100を超えています

品質はこう組み上がります。

```
土台 ＝ 50 ＋ 設備 ＋ 設計 ＋ 木 ＋ 仕上げ
          ↓ ここに、通常工程の判断が積み上がる（上限 35点）
          ↓ 最後に、山場の腕前が掛かる（×0.55〜×1.10）
       品質（100で頭打ち）
```

ところが **設備の品質ボーナスは、合計で +50** あります。

| 設備 | 品質 | 値段 |
|---|---|---|
| がっしりした作業台 | +5 | 5,000円 |
| 塗装ブース | +10 | 10,000円 |
| 刃物研ぎ場 | +8 | 60,000円 |
| 温湿度を保つ木材庫 | +10 | 150,000円 |
| 舶来の彫刻刀ひとそろい | +12 | 420,000円 |
| 銘木市への伝手 | +5 | 400,000円 |

良い素材（+29）に、**たった15,000円ぶんの設備（+15）**を足すだけで、
土台は **50 + 44 = 94**。そこへ工程の35点が乗ると **129**。

**100で切られます。**

### その結果、三つの手が同じ結果になります

6工程の家具で、ぜんぶていねい／ぜんぶふつう／ぜんぶ手早く、を計算しました。

```
   土台のもと            山場   ていねい   ふつう    手早く
   素材わるめ・設備なし            45   65(B)   57(C)   49(C)
   ふつう・設備なし              70   93(S)   83(A)   74(B)
   良い素材・設備なし             70   94(S)   94(S)   88(A)
   良い素材＋設備+20            70   94(S)   94(S)   94(S)   ← 三つとも同じ
                         90  100(S)  100(S)  100(S)   ← 三つとも同じ
   良い素材＋設備+50            70   94(S)   94(S)   94(S)   ← 三つとも同じ
```

**設備を +20 ぶん買った時点で、工程の選択は完全に消えます。**
15場面のうち **6場面で、三つの手がまったく同じ結果**になりました。

先日「三つの手を、ほんとうの選択にする」で時間あたりの効率を直しましたが、
**その手前で、天井に頭をぶつけていた**わけです。

### だから「全部ていねいにやってしまう」

正確には、**全部ていねいにやっても、全部手早くやっても、同じSになる。**
ていねいを選ぶのは、ただ「そのほうが良さそうだから」であって、
**ゲームがそれに応えていません。**

## 3. 直しかた（案）

### ① 素材と設備を、「足し算」から「掛け算」へ　【本命】

土台に足すのをやめて、**全体に掛ける**ようにします。

```
いま   品質 = min(100, (50 + 設備 + 素材 + 工程35) × 山場)
案     品質 = min(100, (50 + 工程35) × 素材設備倍率 × 山場)
                                      （1.00〜1.30）
```

こうすると、**工程の35点は必ず効きます**。掛け算なので、
良い素材・良い設備ほど「ていねいにやった甲斐」も大きくなります。

同じ条件で計算し直すと：

```
   土台のもと            山場   ていねい   ふつう    手早く
   良い素材＋設備+20            70   94(S)   83(A)   72(B)
                         90  100(S)   93(S)   81(A)
   良い素材＋設備+50            70  100(S)   91(S)   79(A)
                         90  100(S)  100(S)   89(A)
```

**三つとも同じになる場面が、15場面中 0 になりました。**

設備を買った意味も残ります（同じ打ち方で、ランクが一つ上がる）。
いちばん上だけは頭打ちになりますが、それは**完璧に打った結果**なので正しい姿です。

### ② 遅れたことを、はっきり言う　【必須】

```
いま   期日内 →「　期日内じゃ！」　／　遅れ → 何も言わない
案     期日内 →「　期日内じゃ！　会心の一台じゃ」
       遅れ   →「　納期を 3時間 過ぎた。売値は2割引き、会心にもならん」
```

さらに、制作中のヘッダーに **「納期まで あと◯時間」** を出し、
**超えたら赤く**します。いまは「あと17h」としか出ていません。

### ③ 納期に、ランクの意味を持たせる　【任意・お好みで】

②まででも筋は通りますが、もっと効かせたいなら。

> **納期を過ぎた家具は、どんなに良くても「とても良いできばえ（A）」止まり。**

木工として筋が通っていますし、一行で書けて、一目で分かります。
ただし**かなり強い**ので、まず②を入れて様子を見るのをお勧めします。

## 4. 入れたもの（①②③＋④）

### ① 素材と設備は、掛け算になりました

```
品質 ＝ min(100, (50 ＋ 工程の積み上げ35) × 仕立ての倍率 × 山場の腕前)
                                        1.00 〜 1.30
```

倍率は `1 ＋ (設備 ＋ 設計 ＋ 木 ＋ 仕上げ) ÷ 260`。
設備ぜんぶ（+50）に最上の素材（+29）を重ねても **×1.30** で止まります。

本物のコードで、15場面を計算し直しました。

```
   土台のもと            仕立て  山場   ていねい   ふつう    手早く
   素材わるめ・設備なし      ×0.99   45    67(B)   59(C)   51(C)
                      ×0.99   70    79(A)   69(B)   60(B)
                      ×0.99   90    88(A)   77(A)   67(B)
   ふつう・設備なし        ×1.06   45    72(B)   63(B)   55(C)
                      ×1.06   70    84(A)   74(B)   65(B)
                      ×1.06   90    94(S)   83(A)   72(B)
   良い素材・設備なし       ×1.11   45    75(A)   66(B)   57(C)
                      ×1.11   70    88(A)   78(A)   67(B)
                      ×1.11   90    98(S)   87(A)   75(A)
   良い素材＋設備3つ       ×1.20   45    80(A)   72(B)   62(B)
                      ×1.20   70    94(S)   84(A)   73(B)
                      ×1.20   90   100(S)   94(S)   82(A)
   良い素材＋設備ぜんぶ     ×1.30   45    80(A)   78(A)   68(B)
                      ×1.30   70    94(S)   92(S)   79(A)
                      ×1.30   90   100(S)  100(S)   89(A)

   三つの手が同じ結果になる場面：0 / 15   （前は 6 / 15）
```

いちばん下の段だけ、ていねいとふつうが並びます。
**設備を全部買い、最上の素材で、山場も90点で打った**ときだけです。
そこまでやった方が頭打ちになるのは、正しい姿だと思います。

設備を買った意味も残りました。同じ打ち方で、ランクが一つ上がります。

```
   山場70・ていねい    設備なし 88(A)  →  設備3つ 94(S)
   山場70・ふつう      設備なし 78(A)  →  設備3つ 84(A) → ぜんぶ 92(S)
```

### ② 遅れたことを、はっきり言うようにしました

制作中の画面に、品質の組み立てが出ます。

```
   工程 72点 × 🪵仕立て ×1.20 × 🔥腕前 ×1.05
   ⏰ 納期を 3 時間すぎた ── 売値は2割引き、会心にもならん
```

遅れている間は、この行が**赤く**出ます。
できあがったときの言葉も変えました。

```
   期日内 →「　期日内じゃ！」
   遅れ   →「　……ただ、納期を 3時間すぎた。売値は2割引き、会心にもならん。」
```

### ③ 遅れたら、A止まりにしました

```js
if (!onTime && rank === "S") rank = "A";
```

満点で打っても、納期を過ぎた家具は「とても良いできばえ」まで。

```
   期日内  100点 S  65,490円
   遅れ    100点 A  38,100円      ← 27,390円 の差
```

会心が付かないので、**章の解放にも、黄金の名匠にも進みません。**
納期は、これではっきり効きます。

### ④ おまけ ── ひらき直すと、かかった時間が巻きもどっていました

直している途中で、もう一つ見つかりました。**こちらが、おそらく本当の犯人です。**

セーブの読みかえが、こう書かれていました。

```js
if (savedVer !== 4 && savedVer !== 5) {     // 第3章までのセーブを直す
  ...
  state.craftUsed = state.stepIndex * 2;    // ← 条件なしで、上書き
}
```

「**版が 4 でも 5 でもなければ直す**」。
いまの版は 18 ですから、**4 でも 5 でもありません。**
つまりこの直しは、**毎回ひらくたびに通っていました。**

```
   15時間かけて保存  →  ひらくと 10時間（＝工程5つ × 2時間）
```

**ブラウザを閉じて開き直すたび、使った時間が「1工程2時間」に書き直されていた。**
ていねいに（3時間ずつ）やった人ほど、時間が消えます。
納期を過ぎていても、ひらき直せば過ぎていないことになります。

同じ書きかたの分岐が **16個**ありました。部屋の家具を下げる直しもその一つで、
ひらくたびに下がり続けます（`migrate18.js` が、それを捕まえました）。

ぜんぶ「**これより古ければ直す**」に改めました。

```js
const sv = typeof savedVer === "number" ? savedVer : 0;
if (sv < 4) { ... }     // 版4より古いセーブだけ直す
```

```
   直す前　　  15時間かけて保存  →  ひらくと 10時間
   直したあと  15時間かけて保存  →  ひらくと 15時間
```

古いセーブは、これまでどおり順に直って最新の版になります。
`vertest.js` が、**同じ版のセーブを二度ひらいても何も変わらない**ことを見張ります。

### 固定したこと

`qtest.js` で、以下が崩れたらテストが落ちます。

- `prepMult` / `baseQuality` があり、割り数は 260
- 土台に、設備や素材を**足し算で積んでいない**
- どの設備の持ちかたでも、三つの手が同じ結果になる場面が **0**
- 遅れたときは S が付かない
- 遅れたときの売値倍率が ×0.80

`vertest.js` では、

- セーブの読みかえが「版 N でなければ」ではなく「版 N より古ければ」で書かれている
- 同じ版のセーブを二度ひらいても、かかった時間・品質・部屋の並べ方が変わらない
- 古いセーブは、ちゃんと最新の版にあがる

セーブは壊れていません。図鑑に残っている過去の記録も、そのままです。
作りかけの家具は、進んだ工程ぶんの積み上げに読み替えました
（`state.ver` を 19 に上げたときの一度だけの手当て）。
