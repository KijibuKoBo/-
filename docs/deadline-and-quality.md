# 「全部ていねいにやってもSになる」の正体

> 「時間を超過してもペナルティがない。全部丁寧にやってしまう。
>  結果Sランクになるが、どーなのだろう」

調べました。**ペナルティはあります。**ただし、お気づきのとおり効いていません。
そして、**もっと大きな問題が別にありました。**まだ実装はしていません。

---

## 1. 納期を過ぎると、何が起きているか

ちゃんと二つ起きています。

| | 期日内 | 遅れ |
|---|---|---|
| **売値の倍率** | ×1.10 | **×0.80** |
| **会心（S・Aのとき）** | つく | **つかない** |

売値の差は、**平均 6,021円**（売値の約27%）。ドクロのキャビネットなら **12,150円** の差です。

そして**会心を逃すほうが、じつは重い**。会心は

- **章の解放**の鍵
- **黄金の名匠／黄金の大匠／祝祭の伝説**の条件

になっています。遅れた家具は、どんなに良くても会心になりません。

### なぜ「ない」と感じるのか

**どこにも出ていないからです。**

- 期日内に間に合うと「　期日内じゃ！」と出る
- **遅れたときは、何も出ない**
- 会心を逃したことも、どこにも書かれない

つまり「良いことが起きなかった」だけで、**「悪いことが起きた」が一度も見えません。**

### それでも、お金の計算は合っています

| | 倍率 |
|---|---|
| 遅れて S | 1.5 × 0.8 = **1.20** |
| 期日内に A | 1.2 × 1.1 = **1.32** |
| 期日内に S | 1.5 × 1.1 = **1.65** |

**遅れたSより、間に合ったAのほうが高く売れます。**
設計としては正しく、効いていないのは**見せかた**だけ、のはずでした。

## 2. ところが、本丸は別にありました

### 土台が、100を超えています

品質はこう組み上がります。

```
土台 ＝ 50 ＋ 設備 ＋ 設計 ＋ 木 ＋ 仕上げ
          ↓ ここに、通常工程の判断が積み上がる（上限 35点）
          ↓ 最後に、山場の腕前が掛かる（×0.55〜×1.10）
       品質（100で頭打ち）
```

ところが **設備の品質ボーナスは、合計で +50** あります。

| 設備 | 品質 | 値段 |
|---|---|---|
| がっしりした作業台 | +5 | 5,000円 |
| 塗装ブース | +10 | 10,000円 |
| 刃物研ぎ場 | +8 | 60,000円 |
| 温湿度を保つ木材庫 | +10 | 150,000円 |
| 舶来の彫刻刀ひとそろい | +12 | 420,000円 |
| 銘木市への伝手 | +5 | 400,000円 |

良い素材（+29）に、**たった15,000円ぶんの設備（+15）**を足すだけで、
土台は **50 + 44 = 94**。そこへ工程の35点が乗ると **129**。

**100で切られます。**

### その結果、三つの手が同じ結果になります

6工程の家具で、ぜんぶていねい／ぜんぶふつう／ぜんぶ手早く、を計算しました。

```
   土台のもと            山場   ていねい   ふつう    手早く
   素材わるめ・設備なし            45   65(B)   57(C)   49(C)
   ふつう・設備なし              70   93(S)   83(A)   74(B)
   良い素材・設備なし             70   94(S)   94(S)   88(A)
   良い素材＋設備+20            70   94(S)   94(S)   94(S)   ← 三つとも同じ
                         90  100(S)  100(S)  100(S)   ← 三つとも同じ
   良い素材＋設備+50            70   94(S)   94(S)   94(S)   ← 三つとも同じ
```

**設備を +20 ぶん買った時点で、工程の選択は完全に消えます。**
15場面のうち **6場面で、三つの手がまったく同じ結果**になりました。

先日「三つの手を、ほんとうの選択にする」で時間あたりの効率を直しましたが、
**その手前で、天井に頭をぶつけていた**わけです。

### だから「全部ていねいにやってしまう」

正確には、**全部ていねいにやっても、全部手早くやっても、同じSになる。**
ていねいを選ぶのは、ただ「そのほうが良さそうだから」であって、
**ゲームがそれに応えていません。**

## 3. 直しかた（案）

### ① 素材と設備を、「足し算」から「掛け算」へ　【本命】

土台に足すのをやめて、**全体に掛ける**ようにします。

```
いま   品質 = min(100, (50 + 設備 + 素材 + 工程35) × 山場)
案     品質 = min(100, (50 + 工程35) × 素材設備倍率 × 山場)
                                      （1.00〜1.30）
```

こうすると、**工程の35点は必ず効きます**。掛け算なので、
良い素材・良い設備ほど「ていねいにやった甲斐」も大きくなります。

同じ条件で計算し直すと：

```
   土台のもと            山場   ていねい   ふつう    手早く
   良い素材＋設備+20            70   94(S)   83(A)   72(B)
                         90  100(S)   93(S)   81(A)
   良い素材＋設備+50            70  100(S)   91(S)   79(A)
                         90  100(S)  100(S)   89(A)
```

**三つとも同じになる場面が、15場面中 0 になりました。**

設備を買った意味も残ります（同じ打ち方で、ランクが一つ上がる）。
いちばん上だけは頭打ちになりますが、それは**完璧に打った結果**なので正しい姿です。

### ② 遅れたことを、はっきり言う　【必須】

```
いま   期日内 →「　期日内じゃ！」　／　遅れ → 何も言わない
案     期日内 →「　期日内じゃ！　会心の一台じゃ」
       遅れ   →「　納期を 3時間 過ぎた。売値は2割引き、会心にもならん」
```

さらに、制作中のヘッダーに **「納期まで あと◯時間」** を出し、
**超えたら赤く**します。いまは「あと17h」としか出ていません。

### ③ 納期に、ランクの意味を持たせる　【任意・お好みで】

②まででも筋は通りますが、もっと効かせたいなら。

> **納期を過ぎた家具は、どんなに良くても「とても良いできばえ（A）」止まり。**

木工として筋が通っていますし、一行で書けて、一目で分かります。
ただし**かなり強い**ので、まず②を入れて様子を見るのをお勧めします。

---

## 4. 決めていただきたいこと

1. **①をやるか**（品質の組み立てを、足し算から掛け算へ）
   - これが本丸です。やらないと、三つの手は設備を買った時点で意味を失います
2. **②をやるか**（遅れたことを言う・納期を出す）── 小さい変更です
3. **③をやるか**（遅れたらA止まり）── 強い。後からでも足せます

セーブは壊れません。図鑑に残っている過去の記録も、そのままです。
（これから作る家具の計算だけが変わります）
