---

## 文章を直したいとき

`proposal.html` を書きかえて、刷り直すだけです。

```bash
cd docs/tools
node pdf.js
```

古いブラウザでも開けるよう、**PDFで渡すことを前提**にしています。
A4・余白18mm、ページ番号つき。いまは8ページ、1.8MB（メールで送れる大きさ）です。

## 画面を撮り直したいとき

ゲームの見た目が変わったら、載せている画面も撮り直します。

```bash
cd docs/tools
node shots.js      # ①職人をつくる ③本物のページ ④仕入れ ⑤図鑑 ⑥設計えらび
node shots2.js     # ②記念証 と 合言葉の欄（要素だけを切り取る）
node pdf.js
```

`seed.json` は、撮るときに使うセーブデータです（職人「けん」・工房Lv5・
催しに参加ずみ）。実績の数字を変えたいときは、ここを直します。

撮影は **`?day=2026-11-08`**（けいこ用の日づけ）で開いています。
開催日を過ぎると合言葉が通らなくなるので、撮り直すときはこの日づけを
新しい開催日に合わせてください。

## 中身を入れかえたとき

催しの日どり・合言葉・ゲームの数字（家具の数、称号の数など）は
`proposal.html` に直書きしてあります。**ゲームを直したら、ここも直してください。**
食い違ったまま会社に渡るのが、いちばん困ります。
