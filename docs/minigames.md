# 山場のミニゲーム 10種 ── ことばによる全容

松永工房クラフトストーリーの「山場（やまば）」で遊ぶ、10種のミニゲームの説明です。
数字は `game/index.html` の `CRAFT_ACTIONS` から起こしています（2026-10-20 時点）。
10種とも、持ち時間・波の組み立て・採点は、この日のコードと一致しています。

---

## 1. 山場とは何か

家具を一台つくる流れは、こうです。

```
設計図をえらぶ → 木と仕上げをえらぶ → 工程をひとつずつ進める → 完成
                                         └─ そのうち1工程だけが「山場」
```

**ふつうの工程**は、三つの選択肢から選ぶだけ。「ていねいに」「ふつうに」「手早く」——
かかる時間と、積み上がる品質がちがいます。ここは**判断**の場です。

**山場の工程**は、選択肢が出ません。かわりに画面いっぱいの盤面が開いて、
**実際に指を動かします**。ここは**手つき**の場です。

家具ごとに山場はひとつだけ。どの工程が山場かは、一度その家具を作ると図鑑に記録され、
次からは作る前に見えるようになります。

### 反射神経を測っていません

10種に共通する設計の芯は、**「速く押せる人が勝つ遊びにしない」**ことです。
測っているのは、**ていねいさ**と**正確さ**。

- 板を**受ける**／**よける**を見分ける（目）
- 節を**よけて**置けるところを探す（読み）
- 帯の**ど真ん中**で止める（間合い）
- 下絵から**離れずに**なぞる（手の落ち着き）
- 線のところで**ちょうど止める**（引きぎわ）

どれも、急げば上手くなるものではありません。

## 2. 10種に共通するしくみ

### 三つの波

どのミニゲームも**3つの波**でできています。進むほど、**速く・狭く・多く**なります。
いま何波目かは、盤面の上に出つづけます。

```
第1波 / 3   節のある板は受けるな        3連続！
```

### 点は 0〜100 点

遊び終わると 0〜100 点が出ます。内訳は4つ。

| 内訳 | 配点 | 何を見ているか |
|---|---|---|
| **命中** | 72点 | 当てたか。取りこぼさなかったか |
| **きわ** | 10点 | そのうち、どれだけ**ど真ん中**で決めたか |
| **連続** | 18点 | いちばん長く続いた**連続成功** |
| **しくじり** | 1回 −3点 | 外した・取り落とした・やりすぎた |

**「きわ」がある遊びと、ない遊び**があります。帯の中心で止める鋸引き、線にぴたりと
重ねる釘打ち、印にそろえる金具、矢印とまっすぐそろえる布張り——この4つは、
ただ入っただけでは満点に届きません。いっぽう「置く」「はめる」遊び（木取り・組立）は、
入れば満点です。きわどさのないものに、きわどさを要求しないためです。

**連続成功が18点ぶんもある**のが、この採点の性格です。たまたま当たるより、
**途切れさせずに続ける**ほうが報われます。手が覚えた、という感じを点にしています。

### しくじっても終わらない

**一度も途中で打ち切られません。**外しても、落としても、遊びは続きます。
ただし点は減ります。これは、催しで初めて触る方が「失敗して終わった」という
後味を持ち帰らないための決まりです。

### 時間切れはある

それぞれに持ち時間があります（下の表）。切れたときも、**そこまでの出来で点が出ます**。
0点にはなりません。

### 難度は家具が決める

家具の売値で 1〜3 の難度がつきます。

| 難度 | 条件 | つらさ |
|---|---|---|
| ★☆☆ ふつう | 売値 8,000未満 | ×0.85 |
| ★★☆ むずかしい | 8,000〜19,999 | ×1.00 |
| ★★★ いちばんむずかしい | 20,000以上 | ×1.15 |

**変わるのは速さ・狭さ・数だけ**で、遊び方そのものは同じです。
高い家具だから別のことを覚え直す、ということはありません。

以下の各項の数字は、**難度★★（倍率1.00）のときの値**です。★では0.85倍にゆるみ、
★★★では1.15倍に締まります（速さは掛け算、間隔と許容幅は割り算で効きます）。

### 入る前に、道具をえらぶ

山場の直前に、ひと呼吸ぶんの判断があります。

| 道具 | 倍率 | 代償 |
|---|---|---|
| 🔨 いつもの道具 | ×1.00 | — |
| ✨ 研ぎたての刃 | **×1.12** | 気を使うので、きょうの調子が **20さがる** |
| 🪵 手になじんだ古い道具 | ×0.92 | そのかわり、**しくじりが出ない** |
| 🎀 あの日の小刀 | ×1.06 | なし（合言葉を入れた方だけ） |

「しくじりが出ない」は、荒れた日のお守りです。点は伸びませんが、崩れません。

### 遊ばずに済ませることもできる

「**ふつうに作る**」を押すと、ミニゲームを飛ばして **50点固定**。
そのかわり **2時間よけいにかかります**。手が震える日や、時間に追われていない日の逃げ道です。

## 3. 10種、ひとつずつ

### ① 木の目利き ── 落ちもの　（60秒）

> 落ちてくる板を受け台で受ける。**節のある板は受けてはならん。**

上から板が降ってきます。受け台は指で左右に動かします。

- **ふつうの板** … 受ける。1点
- **✨ 金の銘木**（12%） … 受ける。**2点**
- **節のある板** … 受けてはいけない。受けるとしくじり
- 良い板を**取り落とした**ときも、しくじり

| 波 | 板の数 | 落ちる速さ | 節の割合 |
|---|---|---|---|
| 1 | 6 | 1.5 | 25% |
| 2 | 7 | 2.0 | 35% |
| 3 | 8 | 2.6 | **45%** |

第3波では**半分近くが節**になります。手を出す遊びから、**手を出さない遊び**へ
性格が変わっていくのが、この10種の一番目に置いた理由です。

満点の分母は「降ってきた良い板の数」です。節ばかり降った回が損にならないようにしてあります。

#### 見た目 ── 水彩の絵本風

この一種だけ、**8ビットのドット絵**で作ってあります。

背景・板・職人は、**水彩の絵本風**で描きおこした絵を貼ってあります。
ゲーム全体（木の温かみ・アンティーク・絵本風）と**同じ世界**です。
HTMLの中に WebP で埋めてあるので、**外から何も読みにきません**（全部で約98KB）。

- 背景は**工房の一枚絵**。光の入る大きな窓、吊りランプ、道具の棚、鑿と鋸、
  そして手前いっぱいの作業台。**動きません**
- 背景は、**作業台の天板の奥ぎわがちょうど 255 に来るように切って**あります。
  受けるところ（230〜258）が、ちょうど台の上になります
- 職人は**両手をひろげて**立っています。指を動かすと、職人ごと左右に動きます。
  **ひろげた手のまん中が、受けるところのまん中**です
- 職人は**天板の奥ぎわで切って**あるので、台のうしろに立って見えます
- 落ちてくる板は**職人より手前**に描いています。頭に隠れて見えない、が起きないためです
- 受けそこねた板は、**作業台のうしろへ消えます**（天板の上を素通りしません）
- 上の帯は**工房の紙**。点・波（三つの丸）・職人コンボ・のこり時間を、工房の字で書いています

板は、色が見えなくても**形で見分けられます**。節の板には、**まん中に節**があります。
銘木は、**飴色に照りが入って**います。

#### 職人の顔は、あなたの顔

受け台を持っている職人の頭は、**工房に登録したあなたの職人の似顔絵**です。
合言葉を入れた方は、**入れてある写真**がそのまま出ます（写真のほうが優先されます）。

職人の絵は、**首から上を消したもの**と**描いてある顔のまま**の二枚を持っています。
似顔絵が出せるときは前者に顔をのせ、出せないときは後者（帽子とひげの職人）をそのまま使います。
似顔絵を変えれば、次に遊んだときから変わります。

**似顔絵をのせるときだけ、体を小さくして組み替えます。**
描いてある職人は3.7頭身ですが、似顔絵はまるい大きな顔なので、
そのままの体にのせると頭でっかちに見えてしまいます。絵の中の寸法
（あご160・手のひら295・ひろげた手205px）から体の縮尺を 0.33 にし、
**顔の高さは103**（あごの位置は動かさず、頭だけが上下する）。
あごから下が141.6なので、**全体で2.4頭身**です。

この等身は、いただいた四面図（帽子・白ひげ・丸めがねの職人）から
**実測して合わせた**ものです ── 帽子のてっぺん〜ひげの下 307 ／ 全体 732 ＝ **2.4頭身**。
顔の高さひとつで動かせます（80なら2.8頭身、71なら3.0頭身）。
**描いてある髭の職人のほうは、もとの形のまま**です。

体を小さくしたので、ひろげた手は67になります（受けられる幅は76）。
板は70あるので、**はしで受けても、ちゃんと手にかかって見えます**。

描いてある顔に戻すのは、一行の差しかえで済みます。

#### はじめの3秒は「見極めろ！」

遊びがはじまって3秒のあいだ、盤の**上の行**に三種の板の絵がならび、
どれを受けてどれをよけるかが出ます。

> **見極めろ！**　[ふつうの板]受ける　[金の銘木]受ける（二枚ぶん）　[節の板]よける

盤の上ではなく**盤の外**に出しているので、落ちてくる板をいっさい隠しません。
3秒たつと、いつもの波の見出しに戻ります。

#### 手ざわり ── 足した演出

| | |
|---|---|
| 板を受ける | 木くずが飛び、画面が短くゆれる |
| 金の銘木 | 木くずが増え、きらりと鳴り、「2」が浮かぶ |
| 節を受けた | **赤く光らせません。**黒っぽい木片が散り、画面が強くゆれる |
| **節をよけた** | 小さな緑の✓が浮かぶ。**点は1点も動きません**が、見ていた証です |
| 波が変わる | 帯が出る（「第 2 波」「節が増えるぞ。よう見よ。」） |

#### 職人コンボ

連続成功が **3・5・10**（以降は5ごと）に届くと、数が大きく浮かび、音が一段ずつ増えます。

| 連続 | 色 | 音 |
|---|---|---|
| 3 | 緑 | 三つの音 |
| 5 | 金 | 四つの音、高く |
| 10〜 | 白 | 五つの音＋**画面のふちが一瞬光る** |

連続成功はもともと18点ぶんを占めています。**その18点が、目と耳で分かるようになった**だけで、
採点は一字も変えていません。

#### 幻の銘木 ── 点に入らない、追加のごほうび

**最終波に、40%の確率で一度だけ**、ふつうの倍ほどの大きさの板が、ふちを光らせながら
ゆっくり降りてきます。

> **幻の銘木**　百年に一度の杢目じゃ。受けよ。

**この板は、0〜100点にいっさい関わりません。**

- 受けても **点は1点も増えません**
- 逃がしても **点は1点も減りません**
- 連続成功も切れません。満点の分母にも入りません

受けると何が起きるか。**結びの称号がひとつ上がります。**

| 点 | 称号 |
|---|---|
| 85以上 | 銘木の目利き |
| 65〜84 | 板を見る目 |
| 40〜64 | 目利き見習い |
| 40未満 | 目利き見習い |

幻の銘木を受けると、ここから**一段上がり**、いちばん上は **「伝説の鑑定眼」**。
KoBoさんも「幻の銘木まで見抜きおったか。」と言い添えます。

**点に入れなかったのは、意図です。**点に入れてしまうと、幻が出た回と出なかった回とで
同じ腕前が違う点になります。それは、この遊びがずっと守ってきた
「ていねいさと正確さだけを測る」という約束を破ります。
幻の銘木は、**点ではなく、記憶に残るもの**として置いてあります。

### ② 木取り ── 詰めこみ　（45秒）

> 下の部材を押してえらび、板の**置きたい所を押す**。**緑なら取れる・赤は取れん。**節をよけるのじゃ。

8×6 の一枚板。ところどころに**節**があります。下の置き場から部材をえらび、
板の上で指を下ろすと、そこに**半透明の影**が出ます。

- **緑** … そこに取れる
- **赤** … 節にかかっている／ほかの部材と重なっている

指を動かせば影も動きます。**板の外で離せば、何も起きません**（置きまちがいの逃げ道）。
取れた瞬間、**カチッ**と鳴って画面が小さくゆれます。

部材は6種。**扉板**（2×3）・**側板**（1×4）・**天板**（3×1）・**棚板**（3×2）・
**鏡板**（2×2）・**台輪**（4×1）。

| 波 | 取る枚数 | 節の数 |
|---|---|---|
| 1 | 2 | 3〜4 |
| 2 | 3 | 4〜5 |
| 3 | 4 | 5〜6 |

#### 波のはじめに、部材を見せます

第N波に入ると、**その波で取る部材が大きく出ます**。落ち着いて置き方を考えてから、
画面を押すと始まります（1.4秒で自動的に始まります）。

#### 理不尽な詰みは、起こりません

盤の作りかたが、ふつうと逆です。

```
① 先に、その波の部材をぜんぶ置いてみる（これが「解」）
② 解に使わなかったマスにだけ、節を置く
```

これで「**ぜんぶ置ける並べかたが、少なくとも一つある**」ことが保証されます。
盤を2000回つくって、**どの盤にも解が実在すること**をテストで確かめています。

それでも、置きかたしだいで手づまりになることはあります。そのときは
**板を一枚替えます**（「この板では、もう取れん」）。**点は1点も動きません。**

#### 名取りボーナス

点には関わらない、見た目のごほうびです。

| | 条件 |
|---|---|
| **名取り！** | 節のとなりに、まわりを埋めて取った |
| **ぴったり** | まわりの3/4以上が、板のはしか他の部材に接している |
| **節をよけた** | 節のとなりに取った |

#### 組み上がり

三波ぶん**9枚を取りきると、取った部材が家具の形に組み上がります**。
天板・側板・鏡板・棚板・扉板・台輪が、それぞれの場所へ飛んでいきます。

#### 見た目

ファミコンの作り（1ドット＝3・太い輪郭・十六色）。
木目は**マスごとではなく、板を横切る一本の線**にしてあります。
マスごとに刻むと、ちらついて盤が読めなくなるためです。

### ③ 鋸引き ── 間合い　（40秒）

> 鋸が行き来する。**緑の帯に重なった瞬間**に画面を押して挽き進める。

鋸が左右に往復します。板の上のどこかに緑の帯。重なった瞬間に押します。

**帯の中心ほど「決まった」**ことになります。端ぎりぎりで入っても、点は伸びません。
中心から22%以内だと「✨ ど真ん中じゃ」。

| 波 | 回数 | 鋸の速さ | 帯の幅 |
|---|---|---|---|
| 1 | 6 | 1.6 | 54 |
| 2 | 7 | 2.3 | 40 |
| 3 | 7 | 3.1 | **28** |

第3波は**帯が約半分、速さが約2倍**。10種のなかで最も「間合い」を測る遊びです。
一度押すたびに帯の位置が変わるので、覚えることはできません。

### ④ 釘打ち ── 拍　（60秒）

> 釘が**光る帯に重なった瞬間**に、その板を叩く。拍を外すと曲がって入る。

工房の作業台に、三枚の板が奥へ伸びています。それぞれに釘が降ってきます。
**手前の光る帯に重なった瞬間、その板を叩きます**。

- 帯からの距離が近いほど、よく決まる（9以内で「✨ ぴたり」）
- 釘がいないところを叩く → **空打ち**。しくじり
- 帯を通りすぎる → 打ちそこね。しくじり（そのまま曲がって入っていきます）
- 打てた釘は、**板に残ります**。やった跡が、そのまま見える

| 波 | 釘の数 | 落ちる速さ | 間隔 |
|---|---|---|---|
| 1 | 8 | 1.7 | 0.70秒 |
| 2 | 9 | 2.3 | 0.56秒 |
| 3 | 9 | 3.0 | 0.46秒 |

**10種でいちばん手数の多い遊び**（計26本）です。音楽ゲームの形をしていますが、
拍は規則正しくありません。板もばらばらに来ます。リズムを覚えるのではなく、
**その一本を見る**遊びです。

#### 絵

松永工房さんの水彩。板の遠近は、**絵から実寸を測って**引いてあります。

```
板の上ぎわ 455px ／ 手前ぎわ 945px（1254px の絵）
継ぎ目の傾き 左 -0.159 ／ 右 +0.154
```

釘は、落ちぐあいに合わせて**遠いほど小さく、手前ほど大きく**なります。
帯も、叩いたときに光るところも、**板の形（台形）にそろえて**あります。

採点・制限時間・難度・波の組み立ては、**もとのまま一行も変えていません**
（`kgtest.js` が見張ります）。

### ⑤ 彫刻 ── 一筆なぞり　（50秒）

> 下絵の線を**一筆でなぞる**。線から離れると彫りが浅くなる。

薄く下絵が描いてあります。指を置いて、離さずに最後までなぞります。

**三回彫ります。**そのたびに、許される幅が狭くなります。

| 回 | 許される幅 | 画面のことば |
|---|---|---|
| 1 | 30 | 「ゆっくりで良い」 |
| 2 | 24 | 「少し細い線じゃ」 |
| 3 | 18 | 「いちばん細い線じゃ」 |

採点は、下絵の通過点（唐草16箇所・花22箇所）のうち**何%に手が届いたか**。
その割合がそのまま22点ぶんに化けます。「78% 彫れた」のように毎回出ます。

**文様は家具ごとに決まっています。**

- **唐草文様** ── つるの根もとから、渦の先まで。うねって伸び、先で渦を巻く一筆。
  （密談椅子・バルコニーチェア・マントルピース・バードケージスタンド）
- **花文様** ── 中心を通って、花びらを五枚。中心を五度くぐる、彫りごたえのある一筆。
  （ドレッサー・ベッドアーチ・オークドレッサー）

指を離すとその回は締め切られます。**途中で手が止まっても、そこまでは彫れています。**

### ⑥ 研磨 ── 追いかけ　（32秒）

> 荒れた所を指でこする。**2回で平ら、4回で削りすぎ**。荒れはどんどん出てくる。

6×4 のマス。濃い色のところが**荒れ**です。指でこすると一段ずつ平らになり、
平らになった瞬間「つやが出た」。それが1点。

**平らなところを触ってはいけません。**穴があきます。しくじりです。

そして——**荒れは、遊んでいるあいだも増えつづけます。**

| 進みぐあい | 荒れの増え方 |
|---|---|
| 0〜7面 | 約1.5秒ごとに1つ |
| 8〜15面 | 約1.5秒ごとに**2つ** |
| 16面〜 | 約1.5秒ごとに2つ（最後まで） |

（間隔は難度で 1.3〜1.8秒。むずかしいほど速く荒れます）

24面を平らにすれば終わり。**持ち時間は32秒。10種でいちばん短い**です。
追いかけっこの遊びなので、長いと作業になってしまうからです。

指を滑らせたまま複数マスをなでられますが、**同じマスは連続で数えません**。
こすりっぱなしで勝てる遊びではありません。

---

### ⑦ 組立 ── 形合わせ　（45秒）

> 下の部材を押してから、**合う窪みを押す**。形と大きさを見て選ぶのじゃ。

上に窪みがいくつか、下の台に部材がならびます。**まず部材を選び、次に窪みを押します。**

部材は6種。**横框**（54×30）・**たて框**（30×60）・**鏡板**（44×44）・
**台輪**（70×22）・**だぼ**（24×24）・**扉板**（36×52）。

下の台では**小さく（72%）**表示されるので、大きさの記憶ではなく、
**縦横の比**で見分けることになります。

| 波 | 窪みの数 |
|---|---|
| 1 | 3 |
| 2 | 4 |
| 3 | 5 |

形がちがえば「⚠️ 形が合わん」でしくじり。手に持っていた部材は台に戻ります。

**時間に追われない遊び**です。10種のなかで、落ち着いて考えられる休憩所の位置づけです。

---

### ⑧ 布張り ── はらう　（60秒）

> しわが出たら、**矢印の向きへ指をはらう**。放っておくと癖がつくぞ。

布の上に、しわが出ます。それぞれに**矢印**（上下左右のどれか）がついています。
しわの上から、その向きへ指をはらいます。

- 向きがそろうほど、よく伸びる（ほぼ真っすぐで「✨ まっすぐ伸びた」）
- 向きがちがう → 「布が寄った」。しくじり
- **放っておくと癖がつく** ── しわのまわりの輪が縮みきると、自動でしくじり

| 波 | しわの数 | 放っておける時間 |
|---|---|---|
| 1 | 6 | 3.4秒 |
| 2 | 7 | 2.7秒 |
| 3 | 8 | **2.1秒** |

しわは**重なって出ます**。2つ3つ同時にあるとき、どれから片づけるかが考えどころです。
残り時間の短いものから——と気づけるかどうか。

10種のなかで、**唯一「待っているだけで減点される」**遊びです。

---

### ⑨ 金具 ── 角度合わせ　（45秒）

> ねじのまわりを指でなぞって**溝を印に合わせ**、指を離して締める。

大きなねじが一本。**緑の印**がどこかの角度についています。
ねじのまわりを指でぐるりとなぞると、溝が回ります。**印に合ったところで指を離します。**

| 波 | 本数 | 許される狂い |
|---|---|---|
| 1 | 4本 | 20度 |
| 2 | 4本 | 14度 |
| 3 | 4本 | **9度** |

外すと「⚠️ 17度ずれておる」と、**何度ずれたかが出ます**。次の一本に活きます。
印にぴたり（許容の30%以内）だと「✨ 寸分の狂いもない」。

ねじは**180度で一周**として扱われます（溝は上下対称なので、どちらを上にしても同じ）。
盤面は黄色く光って「近い」ことを教えてくれます。

**10種でいちばん手数が少なく（12本）、いちばん静かな遊び**です。

---

### ⑩ 塗装 ── 量の見きわめ　（45秒）

> 面をなでると塗料が乗る。**線のところでちょうど止める**。塗りすぎると垂れるぞ。

細長い面がいくつかならびます。指でなでるたびに、塗料が下から上へ溜まっていきます。
面ごとに**赤い線**が引いてあって、そこが「ちょうど」。

- ちょうどで止める → 「✨ ちょうど良い厚みじゃ」。1点
- **一回でも越えると「垂れた」**。しくじり。やり直しはできません
- 塗り終えた面は、もう触ってはいけません

| 波 | 面の数 | 必要な回数 |
|---|---|---|
| 1 | 3 | 2〜3回 |
| 2 | 4 | 2〜4回 |
| 3 | 4 | 2〜5回 |

面ごとに**必要な回数がちがいます**（画面に「2/3」のように出ます）。
なでるたび数が増えるので、見ていれば必ず止められます。

ただし——**指を滑らせたまま隣の面に入ると、そこにも塗料が乗ります。**
これが唯一にして最大の罠です。**手を離して、一面ずつ。**それがこの遊びの答えです。

10種の最後に置いてあるのは、**「やりすぎない」ことだけを問う**遊びだからです。

## 5. 点が、どう家具になるか

山場の点は、そのまま品質にはなりません。**掛け算**になります。

```
品質 ＝ 工程の積み上げ × 仕立て（設備・設計・木・仕上げ） × 腕前（山場の出来）
            50〜85            ×1.00 〜 ×1.30              ×0.55 〜 ×1.10
```

| 山場の点 | 腕前 |
|---|---|
| 0点 | **×0.55** |
| 50点 | ×0.83 |
| 100点 | **×1.10** |

**準備が完璧でも、ここで崩れます。**逆に、材料が多少まずくても、
山場で決めれば持ち直します。遊びの重心をここに置くための配分です。

結果の画面には、その場で先が見えます。

```
      82点
土台 70点 × ×0.96 → 67点  [B]
   このあと 2工程ぶん、土台はまだ伸びる
```

**納期を過ぎた家具は、どんなに良くても A 止まり**です
（満点で打っても「会心」にはなりません。くわしくは
`docs/deadline-and-quality.md`）。

### KoBoさんの評

| 点 | ことば |
|---|---|
| 90以上 | 「職人級じゃ！」 |
| 70〜89 | 「よい仕事じゃ。」 |
| 45〜69 | 「まずまずといったところか。」 |
| 44以下 | 「うむ……次じゃ、次。」 |

加えて、**中身を見た一言**がつきます。「どれもど真ん中じゃ。恐れ入った。」
「14つ続けて決めおった。手が覚えておるな。」「外しはせなんだが、取りこぼしが多いのう。」
——点が同じでも、**どう取った点かで言葉が変わります**。

### きょうの調子が動く

山場の出来は、その日の**調子**を動かします。

| 山場の点 | 調子 |
|---|---|
| 90以上 | **+12**（乗ってきた） |
| 70〜89 | +5 |
| 45〜69 | 0 |
| 45未満 | **−8**（下限10で止まる） |

**上がるほうを厚く、下がるほうを薄く**してあります。一度の失敗が後まで尾を引かないためです。
なお、**調子は山場の点には影響しません**。流れは一方通行です。

```
腕（ミニゲームの出来） → 調子 → ふつうの工程の出来
```

### 腕まえ ── 自分の顔が残る

10種それぞれの**平均点と回数**が、工房の画面に★で残ります。

```
木の目利き   ★★★★☆   平均78点・12回
鋸引き       ★★☆☆☆   平均44点・7回
彫刻         ★★★★★   平均91点・4回
```

**数値を上げても強くはなりません。**自分がどんな職人かを映すだけの鏡です。
家具ごとの**自己ベスト**も別に記録され、山場の結果画面に出ます。

## 6. 音

音を🔊にしていると、山場だけ音の層が変わります。

- **入ると、低い持続音が鳴りはじめます**（緊張の音）。終わると止まります
- **決めるたびに音が上がります** ── 連続成功のたび、音階を一段ずつ登ります
  （0, 2, 4, 7, 9, 12, 14, 16, 19, 21, 24, 26, 28）。**連続するほど高く、明るく**
- **ど真ん中で決めると、音が澄みます**（「きわ」のある4種）
- **外すと、鈍い音**
- **終わると、出来に応じたひとふし**

| 点 | 音 |
|---|---|
| 90以上 | 5つの音が駆け上がり、最後にきらりと二つ（やったー） |
| 70〜89 | 4つの音が上がる |
| 45〜69 | 3つの音が、控えめに |
| 44以下 | 3つの音が、そっと下りる |

**連続成功が音で分かる**のが、この設計の要です。画面を見ていなくても、
いま乗っているかどうかが耳で分かります。

## 7. 山場だけを遊ぶ（けいこ・会場用）

### `?mg=1` ── 工房の中に、十種のけいこ

URL の末尾に `?mg=1` を付けると、工房の画面に **「🔥 山場のけいこ」** が出ます。

- 10種を、**家具を作らずに**ためせます
- 難度 ★／★★／★★★ を選べます
- **点は記録に残りません**（腕まえにも自己ベストにも影響しません）

ゲーム本体はそのまま出ます。調整のときに使う形です。

### `?mg=<山場の名前>` ── その一本だけ

URL の末尾に山場の名前を書くと、**その一本だけの画面**になります。

```
…/game/?mg=mekiki
```

- 見出し・本体・工程・足もとを、**ぜんぶ畳みます**
- はじめての方でも、**似顔絵づくりも工房の案内も通りません**
- **開いた瞬間に始まります**。ブラウザのタブも、その山場の名前になります
- 遊び終わるか ✕ を押すと「とびら」へ。**はじめる**／**難度**／**工房ぜんぶで遊ぶ**
- セーブには一切さわりません

名前は10種のどれでも：`mekiki`／`kidori`／`nokogiri`／`rhythm`／`hori`／
`kenma`／`kumi`／`hari`／`kanagu`／`tosou`。
知らない名前を書かれたときは、ふつうの工房がひらきます。

会場で「ちょっとだけ触ってみたい」という方に、この一本を渡せます。

## 8. どの家具で、どれが出るか

山場に出るミニゲームは、**工程の名前**から自動で決まります。
「扉を組む」なら組立、「表面を磨く」なら研磨、というように。

ただし、**家具ごとに上書き**してあるものがあります。工程の名前からは出ない遊びを、
その家具の見どころに合わせて当ててあるものです。

| 家具 | 出る遊び | なぜ |
|---|---|---|
| ベンチ・ブックヌック・ジュエルトランク・レターラック | 木の目利き | 板の良し悪しが仕上がりを決める家具 |
| チェスト・ロールトップデスク・タイプライター・バニティボックス | 釘打ち | 同じものを、同じ深さで繰り返す仕事 |
| ワードローブ・ハンガーラック・パウダーテーブル | 木取り | 一枚板から、形のある部材を取る |
| ムーンシェルフ・ムーンベッド・ゴシックスクリーン・ローズチェア | 鋸引き | 糸のこで、曲線や透かしを挽き抜く |

**同じ「組立」の工程でも、家具によって別の遊びにできる**ようにしてあります。

## 9. 足すときは

11種目を足すのは、**ファイルの1箇所に項目を1つ増やすだけ**です。

```
CRAFT_ACTIONS に キー を1つ足す
  name   … 画面に出す名前
  limit  … 持ち時間（ミリ秒）
  tip    … 入る前に出すひとこと
  start(svg, ui, done, lv)
```

`start` に渡ってくるもの。

| | |
|---|---|
| `svg` | 300×300 の盤面。ここに自由に描く |
| `ui.progress(0〜1)` | 上のバー |
| `ui.say(文字)` | 盤面の下のひとこと |
| `ui.setTip(HTML)` | 盤面の上の見出し（第◯波／◯） |
| `ui.onDown / onPoint / onUp` | 指の操作。ここに関数を入れる |
| `ui.onTimeout` | 時間切れ。必ず `done` を呼ぶこと |
| `ui.onStop` | 後片付け（`setInterval` を止める） |
| `done(点, ひとこと)` | 終わり |
| `lv` | 難度 1〜3 |

採点は `actScore(総数)` を使えば、命中・きわ・連続・しくじりの配分も、
音も、KoBoさんの一言も**全部ついてきます**。`ok(1, 決まりぐあい)` と `ng()` を
呼ぶだけです。

工程の名前と結びつけるには `STEP_TYPE_OF`、家具で上書きするには `ACTION_OF` に
1行ずつ足します。
