# ドールハウス機能 ── やる前のご相談

> 作った家具をドールハウスに並べて、うちの子を飾って、ゲームの中で撮影して、
> 撮った写真を飾っておける場所をつくる。

大きな追加になるので、**着手前の段取り書**です。
これでよいか見ていただいてから手を動かします。

---

## 1. できるとわかったこと

先に素材を調べました。**思っていたよりずっと有利です。**

| | |
|---|---|
| **家具の写真が61枚、すべて背景が抜けてある** | 高さ190ピクセルにそろったRGBA。そのまま重ねて置けます |
| 50種のうち **48種に実物写真がある** | 絵（SVG）は9種だけですが、写真があるので足ります |
| 写真ぜんぶで537KB | すでにゲームに入っている分。**新しく絵を描く必要がありません** |
| KoBoの絵も背景抜き済み | 部屋の隅に立たせることもできます |

つまり **「作った家具を部屋に置く」は、新しい絵を一枚も描かずに作れます。**
これが一番重たい所だと思っていたので、いけます。

---

## 2. どういうものを作るか

### 🏠 ドールハウス（飾り部屋）

- 下のボタンから開く、独立した画面
- **図鑑で1台以上作った家具だけ**が、置ける家具として並ぶ
  → 置きたいものがあるから作る、という流れになります
- 一台ずつ **動かす・大きさを変える・左右を反転する・前後を入れかえる・外す**
- 指でドラッグ、二本指で拡大。スマホで触って気持ちよく動くことを第一にします
- 置いた位置は保存。開き直せば、そのまま

**大きさは自由に変えられるようにします。** 写真の高さが190ピクセルにそろっているので、
実寸の比率とはちがいます。計算で合わせるより、目で見て並べていただくほうが
ドールハウスらしいし、確実です。

### 🧸 うちの子

- 写真を取りこんで、部屋に立たせる
- **透過PNGなら、そのまま使えます。** iPhoneなら写真を長押しして「切り抜き」、
  Androidなら Google フォトの切り抜きで作れます。これが一番きれいです
- 無地の背景で撮った写真なら、ゲーム側で自動で抜きます（しきい値のつまみ＋消しゴム）
- **何人でも登録できるように**します。お名前もつけられます

### 📷 撮影

- 画面にファインダーの枠が出て、シャッターを押すと一枚になる
- 撮れた写真には、日付と、工房の落款を小さく入れます
- お人形の名前を添えるかどうかは選べるように

### 🖼 写真棚

- 撮った写真が並ぶ棚。タップで大きく見られる
- **一枚ずつ端末に書き出せる**ようにします（SNSに上げたり、印刷したり）
- 枚数には上限を置きます（後述）

## 3. 気をつけること（技術の話）

### いまのセーブを壊さないこと

写真は大きいので、**セーブとは別の保管場所**（別の localStorage キー）に入れます。
写真があふれても、職人の記録には一切さわりません。これは譲りません。

### 保管できる量

ブラウザが一つのサイトに持たせてくれる量は、だいたい5MBです。

| | |
|---|---|
| うちの子の写真 | 1人 約50KB（長辺420ピクセル、WebP） |
| 撮った写真 | 1枚 約100KB（900×600、WebP） |
| **上限の目安** | うちの子8人・写真12枚くらい |

いっぱいになったら「古い写真を外してください」と出します。
黙って消したり、壊れたりはさせません。

### 端末をまたげないこと

ブラウザの保管場所は**その端末のそのブラウザだけ**のものです。
スマホで飾った部屋は、自宅PCには出てきません。

そこで **書き出し／読みこみ**をつけます。部屋とうちの子と写真を
一つのファイルに落として、別の端末で読みこめるように。

## 4. 部屋の背景 ── ここだけ、お願いがあります

部屋の背景は、二つのやり方があります。

| | |
|---|---|
| **A・実物のドールハウスの写真** | **これが圧倒的にいい。** 本物の木の質感の中に、本物の家具の写真が並ぶ |
| B・絵で部屋を描く | 板張りの床・漆喰の壁・窓。すぐ作れますが、絵本の絵の中になります |

**A でいきたいです。** 工房のドールハウスの中を、**正面から、まっすぐ**撮った写真を
いただけませんか。

- 部屋の中が空の状態（家具を入れる前）
- カメラを床の高さに近づけて、正面から。見下ろさない
- 部屋が一部屋ずつ分かれていれば、一部屋ずつ
- 明るい所で。影が強いと家具を置いたとき浮きます

いただけるまでは B の絵の部屋で作っておいて、写真が来たら差しかえます。
**写真が来なくても機能は完成します**ので、待たずに進められます。

---

## 5. 思いついたこと（やるかどうかは別）

家具の写真が全部**実物**なので、この部屋は
**「うちの家具を置いたらどう見えるか」のお試し画面**にもなります。

お客さまが自分のドールハウスの写真を取りこんで、
買おうか迷っている家具を置いてみる ── という使い方ができます。
ゲームの中では「作った家具だけ」ですが、
別口でお客さま向けに開くこともできます。

会社へのご提案にも足せる話だと思います。いまは書き留めておくだけにします。

---

## 6. 段取り

四つに分けます。**どこで止めても、そこまでで使えるもの**になります。

| | やること | 大きさの目安 |
|---|---|---|
| **一期** | ドールハウスの画面／家具を置く・動かす・保存 | いちばん重い。全体の半分 |
| **二期** | うちの子を取りこんで立たせる | 四分の一 |
| **三期** | 撮影と写真棚、書き出し | 五分の一 |
| **四期** | 称号や図鑑との連動、部屋ごと書き出し／読みこみ | おまけ |

**一期だけでも、作った家具を並べて眺める所までは行きます。**

### クレジットのこと

**残りがいくらあるか、私からは見えません。** 見る手立てを持っていないので、
正直に申し上げておきます。

かわりに、**一期を終えた所でいちど区切ります。**
そこで残りを見ていただいて、二期に進むか決めていただくのがいいと思います。
一期は、それ自体で完成したものとしてお渡しします。

---

## 7. 決めていただきたいこと

1. **この段取りでよいか**
2. **一期ずつ区切って進めてよいか**（それとも一気に四期まで）
3. **ドールハウスの写真をいただけるか**（なくても進めます）
4. 名前 ── 画面の名前を「ドールハウス」「写真棚」にしていますが、
   工房での呼び方があればそちらに合わせます
