# 木のQRカードを作ってもらうためのプロンプト

催しに来てくださった方へ、その場でお渡しする **木のQRカード**の意匠を
画像生成AI（ChatGPT など）に描いてもらうための指示文です。

**表と裏で2枚**作ります。刻むときも別の版になるので、別々に描いてもらいます。

---

## このカードは「お知らせ」ではありません

**当日、目の前にいる方へお渡しするもの**です。
だから、日付や場所をお知らせする必要はありません。
参加費や申し込み方法も、もう済んだ話です。

書くことは、ほんとうは3つだけです。

| | |
|---|---|
| **お礼** | おこしくださって ありがとうございます |
| **記念** | 催しの名前と日付。あとで見て「あの日」と思い出せる |
| **おみやげ** | QRと合言葉。おうちでゲームのつづきができます |

日付は**記念の一行**として入れます。見出しにはしません。

### 表と裏の分けかた

| | |
|---|---|
| **表** | 絵・お礼・記念の日付・工房名。<br>引き出しから出てきたときに見える顔です。**QRは置きません。** |
| **裏** | QRと合言葉。おうちへの入り口です。<br>絵はほとんど描かず、QRが読めることを第一にします。 |

---

## はじめに ── 画像生成AIにできないこと

**QRコードは描かせないでください。**
画像生成AIが描くQRは、見た目がQRなだけで**必ず読み取れません**。
点の並びには厳密な決まりがあり、AIはそれを守れないからです。

だから、プロンプトでは
**「QRの場所だけ空けておいて」** とお願いします。
本物のQRは、あとからこちらで作って貼ります。

同じ理由で、**日本語の文字も崩れることがあります。**
できあがったら、下の「入れる文字」と一字ずつ見くらべてください。
一文字でもちがったら、作り直すか、文字だけ入れ直してください。

---

## 作るのは2種類 × 表裏

| カード | 渡す相手 | 裏のQRに入れるURL |
|---|---|---|
| **A・当日のお礼カード** | 催しに来てくださった方 | `https://kijibukobo.github.io/-/game/?k=neko` |
| **B・いつでものカード** | 通りすがりの方、お子さん、お店で | `https://kijibukobo.github.io/-/game/` |

B には日付も合言葉も入れません。催しが終わっても使えるようにしておくためです。

---

## A・表（ここからコピー）

```
木製カードの「表」の意匠を描いてください。実際に木に刻んで、
イベントの当日に来場された方へお渡しするものです。

■ これは何か
静岡の家具工房「有限会社 松永工房」が、ドール（人形）用のミニチュア家具を
作っています。その工房のイベントに来てくださった方へ、その場でお渡しする
名刺サイズの木のカードです。お礼と、記念のしるしを兼ねています。
裏面にQRコードが入りますが、この絵は表面なので、QRは出てきません。

■ かならず守ってほしいこと

1. QRコードは描かないでください。四角い枠も要りません。
   これは表面で、QRは裏面にあります。

2. 下に挙げる文字を、一字一句そのまま入れてください。
   言いかえたり、足したり、英訳を添えたりしないでください。

3. ここに書いていない情報は、入れないでください。
   これはお知らせではなく、当日お渡しするお礼のカードです。
   参加費・申し込み方法・開催時刻・住所・電話番号・SNSのIDは
   いっさい書かないでください。

4. 文字は、絵の上に重ねないでください。
   読めなくなるので、文字は文字だけの場所に置いてください。

■ 入れる文字（この通りに）

  〔いちばん大きく、上に〕
  おこしくださって ありがとうございます

  〔小さく、記念の一行として。見出しにはしない〕
  ドール工房ツアー　2026年11月8日

  〔いちばん下に、小さく〕
  有限会社 松永工房

■ 絵柄

  ・水彩絵本のような、やわらかい手描き。木のあたたかみ。
  ・アンティーク家具の工房らしい、落ち着いた上品さ。
    かわいらしくしすぎない。ポップにしない。
  ・色は、木の色（生成り・茶・こげ茶）と深緑を基本に。
    赤はほんの差し色だけ。
  ・背景は、木の板の木目。節や導管がうっすら見える程度に。

■ 絵に入れるもの

  ・工房の老職人をひとり。緑のベレー帽、丸いめがね、白いあごひげ、
    革のエプロン。やさしい顔で、見送るように手をふっている。
    （このゲームの案内役です。主役は家具なので、小さめに）
  ・ミニチュアの家具をいくつか。椅子・小さなたんす・姿見・ランプなど。
    人形そのものは描かないでください。
  ・葉や小さな実の飾りを、縁にひかえめに。

■ 形と大きさ

  ・横長。縦横の比は 91 : 55（名刺の比）。
  ・外周に 4mm の余白。そこには何も描かない。
  ・角は、ゆるく丸める。

■ 刻み方（どちらかを選んでこの行を残してください）

  〔レーザー刻印〕濃淡は3段まで。細い線と細かい点は使わない。
  いちばん細い線でも 0.4mm 以上。塗りつぶしは面で、グラデーションは使わない。

  〔木に直接印刷〕ふつうの水彩画として、濃淡は自由に。

■ 出力

  文字が一字でも崩れたら、やり直してください。
  とくに「松永工房」「ドール工房ツアー」は、念入りに確かめてください。
```

## A・裏（ここからコピー）

```
さきほどの木製カードの「裏」の意匠を描いてください。
表と同じ木、同じ雰囲気で、こちらにはQRコードが入ります。

■ いちばん大事なこと
この面は、スマホでQRを読むための面です。
読みやすさがすべてで、絵は引き立て役にすぎません。
飾りを足して読みにくくするくらいなら、何も描かないでください。

■ かならず守ってほしいこと

1. QRコードは描かないでください。
   カードの中央に 22mm×22mm の正方形の余白を取り、
   細い枠線だけを引いて、中は何も描かず真っ白にしてください。
   本物のQRは、あとからこちらで貼ります。

2. その正方形のまわり 5mm には、木目も飾りも文字も、
   いっさい入れないでください。まっさらな余白にしてください。
   （QRのまわりが汚れていると読み取れません）

3. 下に挙げる文字を、一字一句そのまま入れてください。
   足したり、英訳を添えたりしないでください。

4. 表と天地をそろえてください。
   カードを左右にめくったときに、裏の文字が逆さにならないように。

■ 入れる文字（この通りに）

  〔正方形の上に〕
  おうちでも、ちいさな家具づくりを

  〔正方形のすぐ下に、小さく〕
  工房のゲームがひらきます

  〔いちばん下に、少しだけ大きく〕
  合言葉　ねこあし

■ 絵柄

  ・背景は、表と同じ木の板の木目だけ。うすく、おとなしく。
  ・絵は描かないか、四隅に葉を一枚添える程度にとどめてください。
  ・色は木の色だけ。濃い色は使わない。
  ・中央の正方形の下に、濃い木目や節が来ないようにしてください。

■ 形と大きさ

  ・横長。縦横の比は 91 : 55（表と同じ）。
  ・外周に 4mm の余白。そこには何も描かない。
  ・角は、ゆるく丸める。

■ 刻み方（表で選んだのと同じほうを残してください）

  〔レーザー刻印〕濃淡は3段まで。いちばん細い線でも 0.4mm 以上。

  〔木に直接印刷〕ふつうの水彩画として、濃淡は自由に。

■ 出力

  「ねこあし」の4文字は、念入りに確かめてください。
  ここが一文字ちがうと、合言葉が通りません。
```

## B・いつでものカード

A のプロンプトから、**「これは何か」と「入れる文字」だけ**を
下のものに差しかえます。あとはそのままです。

### B・表

```
■ これは何か
静岡の家具工房「有限会社 松永工房」が、ドール（人形）用のミニチュア家具を
作っています。その工房が配る名刺サイズの木のカードです。
裏面にQRコードが入りますが、この絵は表面なので、QRは出てきません。

■ 入れる文字（この通りに）

  〔いちばん大きく、上に〕
  ちいさな家具を、つくってみませんか

  〔いちばん下に、小さく〕
  ドール家具の工房　有限会社 松永工房
```

職人は「見送るように手をふっている」ではなく
「**招くように手を差しだしている**」に変えると、こちらのカードには合います。

### B・裏

```
■ 入れる文字（この通りに）

  〔正方形のすぐ下に、小さく〕
  工房のゲームがひらきます
```

合言葉の行はありません。文字が一行だけになるので、
正方形はもう少し大きく（26mm）、カードの中央に置いてください。

---

## できあがったら

1. **文字をひとつずつ確かめる。**とくに工房名と「ねこあし」。
2. **裏の正方形の中に、本物のQRを貼る。**
   入れるURLは上の表のとおり。短縮URLは使わないでください
   （リンク切れの元になります）。
3. **表と裏の天地がそろっているか見る。**
   左右にめくって、裏が逆さにならないこと。
4. **実際にスマホで読んでみる。**
   木に刻んだあとだと直せないので、紙に刷って一度ためしてください。
   木目の濃い所にQRが重なると読みにくくなります。

## 次の催しのとき

A で書きかえるのは、ふつうこの2つだけです。

| | どこ |
|---|---|
| 記念の一行 `ドール工房ツアー　2026年11月8日` | 表 |
| 合言葉 `ねこあし` とURLの `?k=neko` | 裏 |

合言葉とURLの `?k=` は、ゲーム側の `EVENTS` と同じものにしてください
（[game/README.md の「工房の催し」](../game/README.md)）。
ここが食いちがうと、カードを読んでも合言葉が通りません。

B は書きかえる所がありません。刷りためておけます。

---

## 合言葉が通る日（決まっています）

**2026年11月8日・9日の2日間だけ**です。広げません。
来てくださった方だけのもの、という線をはっきりさせるためです。

ただし、**日が過ぎてもカードは死にません。**
QRを読めばゲームはいつでも開いて、ふつうに遊べます。
通らなくなるのは合言葉だけで、そのときはKoBoがこう言います。

> その合言葉は、たしかに聞いたことがある。
> ……じゃが、その日は過ぎてしもうた。

だから、カードに「11月9日まで」のような期限は書きません。
書くと、持ち帰ったカードが切れもののように見えてしまいます。
