# 木のQRカードを作ってもらうためのプロンプト

催しで来場された方にお渡しする、**木のQRカード**の意匠を
画像生成AI（ChatGPT など）に描いてもらうための指示文です。

催しごとに日付と合言葉だけ書きかえれば、そのまま使えます。

---

## はじめに ── 画像生成AIにできないこと

**QRコードは描かせないでください。**
画像生成AIが描くQRは、見た目がQRなだけで**必ず読み取れません**。
点の並びには厳密な決まりがあり、AIはそれを守れないからです。

だから、プロンプトでは
**「QRの場所だけ空けておいて」** とお願いします。
本物のQRは、あとからこちらで作って貼ります。

同じ理由で、**日本語の文字も崩れることがあります。**
できあがったら、下の「入れる文字」と一字ずつ見くらべてください。
一文字でもちがったら、作り直すか、文字だけ入れ直してください。

---

## 作るのは2種類

| カード | QRに入れるURL | 渡す相手 |
|---|---|---|
| **合言葉入り** | `https://kijibukobo.github.io/-/game/?k=neko` | 来場された方 |
| **合言葉なし** | `https://kijibukobo.github.io/-/game/` | 通りすがりの方、お子さん |

意匠は同じで、**合言葉の行があるか無いか**だけがちがいます。

---

## プロンプト（ここからコピー）

```
木製カードの意匠を描いてください。実際に木に刻んで、イベントで配るものです。

■ これは何か
静岡の家具工房「有限会社 松永工房」が、ドール（人形）用のミニチュア家具を
作っています。その工房が開くイベントで、来場された方にお渡しする
名刺サイズの木のカードです。カードのQRを読むと、工房が作った
ブラウザゲームが開きます。

■ かならず守ってほしいこと

1. QRコードは描かないでください。
   カードの右下に 22mm×22mm の正方形の余白を取り、
   細い枠線だけを引いて、中は何も描かず白いままにしてください。
   本物のQRは、あとからこちらで貼ります。

2. 下に挙げる文字を、一字一句そのまま入れてください。
   言いかえたり、足したり、英訳を添えたりしないでください。

3. ここに書いていない情報は、入れないでください。
   とくに、参加費・申し込み方法・住所・電話番号・SNSのIDは
   書かないでください。

4. 文字は、絵の上に重ねないでください。
   読めなくなるので、文字は文字だけの場所に置いてください。

■ 入れる文字（この通りに）

  有限会社 松永工房
  ドール工房ツアー
  2026年11月8日（日）
  合言葉　ねこあし
  このカードのQRから、工房のゲームで遊べます

■ 絵柄

  ・水彩絵本のような、やわらかい手描き。木のあたたかみ。
  ・アンティーク家具の工房らしい、落ち着いた上品さ。
    かわいらしくしすぎない。ポップにしない。
  ・色は、木の色（生成り・茶・こげ茶）と深緑を基本に。
    赤はほんの差し色だけ。
  ・背景は、木の板の木目。節や導管がうっすら見える程度に。

■ 絵に入れるもの

  ・工房の老職人をひとり。緑のベレー帽、丸いめがね、白いあごひげ、
    革のエプロン。やさしい顔で、こちらに手をふっている。
    （このゲームの案内役です。主役は家具なので、小さめに）
  ・ミニチュアの家具をいくつか。椅子・小さなたんす・姿見・ランプなど。
    人形そのものは描かないでください。
  ・葉や小さな実の飾りを、縁にひかえめに。

■ 形と大きさ

  ・横長。縦横の比は 91 : 55（名刺の比）。
  ・外周に 4mm の余白。そこには何も描かない。
  ・角は、ゆるく丸める。

■ 刻み方（どちらかを選んでこの行を残してください）

  〔レーザー刻印〕濃淡は3段まで。細い線と細かい点は使わない。
  いちばん細い線でも 0.4mm 以上。塗りつぶしは面で、グラデーションは使わない。

  〔木に直接印刷〕ふつうの水彩画として、濃淡は自由に。

■ 出力

  文字が一字でも崩れたら、やり直してください。
  とくに「松永工房」「ドール工房ツアー」「ねこあし」は、
  念入りに確かめてください。
```

---

## 合言葉なしのほうを作るとき

上のプロンプトから、この2行を消してください。

```
  合言葉　ねこあし
```

そのうえで、文字の指定をこう直します。

```
■ 入れる文字（この通りに）

  有限会社 松永工房
  ドール工房ツアー
  2026年11月8日（日）
  このカードのQRから、工房のゲームで遊べます
```

---

## できあがったら

1. **文字をひとつずつ確かめる。**とくに工房名と合言葉。
2. **QRの枠の中に、本物のQRを貼る。**
   入れるURLは上の表のとおり。短縮URLは使わないでください
   （リンク切れの元になります）。
3. **実際にスマホで読んでみる。**
   木に刻んだあとだと直せないので、紙に刷って一度ためしてください。
   木目の濃い所にQRが重なると読みにくくなります。

---

## 次の催しのとき

書きかえるのは、ふつうこの3つだけです。

| | |
|---|---|
| 催しの名前 | `ドール工房ツアー` |
| 日付 | `2026年11月8日（日）` |
| 合言葉とURL | `ねこあし` ／ `?k=neko` |

合言葉とURLの `?k=` は、ゲーム側の `EVENTS` と同じものにしてください
（[game/README.md の「工房の催し」](../game/README.md)）。
ここが食いちがうと、カードを読んでも合言葉が通りません。
