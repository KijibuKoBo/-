# インスタグラム用　投稿文と素材

ゲーム「松永工房クラフトストーリー」をインスタで紹介するための一式です。
画像・動画は、**ぜんぶ実際のゲーム画面**から撮ってあります（はめ込みではありません）。

---

## 1. 素材

| | 中身 | 大きさ | 枚数・長さ |
|---|---|---|---|
| **カルーセル** | `ig-01`〜`ig-07`（jpg / png） | 1080×1350（4:5） | 7枚 |
| **リール** | `reel-1080x1920.mp4` | 1080×1920（9:16） | 33秒・音なし |

カルーセルは **01 から順に** 入れてください。1枚目がドールハウス、
最後がURLの案内になっています。

リールは音が入っていません。インスタの音楽をあとから付けてください。
静かな曲（木の音・ピアノ・アコースティック）が画に合います。

```

そのままブラウザのゲームにしました。

◆ 出てくる家具は、ぜんぶ本物
うちのドール家具ブランド Petit.Continue の写真を、
そのまま図鑑に入れてあります。寸法も、ほんとうの寸法です。
家具は46種。ぜんぶ集めると図鑑が埋まります。

◆ 一台つくるのに、六つの工程
木取り、組立、研磨、彫刻、塗装、検品。
ていねいにやれば仕上がりは良くなりますが、そのぶん時間を食います。
納期もあります。急ぐか、ていねいにやるか。そこが悩みどころです。

◆ 一台に一度、「山場」が来ます
ここだけは、自分の手で。
釘を打つ、節のある板をよける、鋸を引く──全部で10種類あります。

◆ できた家具は、お部屋に並べられます
本物のドールハウスのお部屋に置いて、写真が撮れます。お部屋は五つ。

ブラウザを開くだけ。無料、登録もいりません。
記録は、お使いの端末の中にだけ残ります。

▶ プロフィールのリンクから遊べます
　kijibukobo.github.io/-/game/
```

## 4. 見本の職人の名前

画像と動画に出てくる職人は **「くるみ」** という見本の名前にしてあります
（ウォールナット＝胡桃から。実在の方の名前は使っていません）。

変えたいときは `docs/tools/ig/seed.js` の

```js
player: { name: "くるみ", avatar: state.player.avatar },
```

を書きかえて、`node shots.js && node build.js`（画像）と
`node rec.js && bash reel.sh`（動画）を走らせ直してください。

> なお、ご提案書に使った `docs/shots/cert.jpg` のほうは、
> 以前の見本のまま **「けん」** になっています。
> そちらも直すか、そのままにするか、お申しつけください。

## 6. 作り直すとき

素材はすべて、スクリプトで組み立て直せます。

```
scratchpad/ig/
  seed.js      … 見本のセーブ（家具18台・お部屋5つぶんの並べ方）
  shots.js     … ゲームの画面を撮る
  frames.json  … カルーセルの文言
  build.js     … カルーセル 7枚を組む
  rec.js       … 実際に遊んで動画を録る
  reel-bg.js   … リールの下敷きを作る
  reel.sh      … 動画を切って、下敷きに乗せて、つなぐ
```

文言を変えるだけなら `frames.json` と `reel-bg.js` の見出しを直して、
`node build.js` と `node reel-bg.js && bash reel.sh` を走らせます。
