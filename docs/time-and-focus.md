# 時間と集中力を、作り直す

> 「1日の定義がモヤッとする。集中力も正直わかりづらい」

その通りでした。**なぜそうなっていたか**を先に書いて、
そのあとに新しい形をまとめます。まだ実装はしていません。

---

## 1. いま、なぜわかりづらいのか

### 集中力は、ほとんど何もしていません

1日の上限は **8時間 ／ 集中力100**。ていねいな手は **3時間・集中30**。

| | 時間で打てる手 | 集中力で打てる手 | 先に尽きるのは |
|---|---|---|---|
| ていねい | 2.67 | 3.33 | **時間** |
| ふつう | 4 | 8.3 | **時間** |
| 手早く | 8 | 20 | **時間** |
| 山場 | 2.67 | 3.33 | **時間** |

**どの打ち方でも、時間が先に尽きます。**
「集中力が足りなくて手が選べない」は一度も起きません。

「つかれた（集中30未満で山場 ×0.85）」も**発動しません**。
30を切るのは一日の最後の一手の直後で、その瞬間に日が変わって100に戻るからです。

唯一効くのが、時間を伸ばす設備だけ買って集中力の設備を買わなかったとき
（11時間／100）。この狭い場合だけ、わずかに集中力が先に尽きます。

**一日中ただ減っていくだけの数字**を眺めていたことになります。

### 根っこの問題

**時間と集中力が、同じ種類のもの（使うと減る持ち物）だった。**
同じ種類が二つあると、片方は必ず余ります。余ったほうは意味を失います。

---

## 2. 新しい形 ── 種類を分ける

| | 何か | どうなる |
|---|---|---|
| **時間** | **使うもの** | 朝8時に始まり、使うと減って、17時に日が暮れる |
| **集中力** | **今日の調子** | 朝きまる。**作業では減らない** |

**作業で減るのは時間だけ。**集中力は、その日の腕の冴えを表す目盛りで、
減らしながら使うものではありません。

種類が違うので、もう混ざりません。

---

## 3. 時間 ── 工房の時計

```
   8:00 ──────── 12:00  昼休み  13:00 ──────── 17:00
```

**8:00〜17:00。昼休みが1時間。働くのは8時間。**

いまと**まったく同じ8時間**です。balanceは一切変えずに、
読めるものにするだけです。

ヘッダーの表示をこう変えます。

| いま | 変えたあと |
|---|---|
| `📅 5日目　⏱ 7h` | `📅 5日目　🕙 10:00（日暮れまで7時間）` |

- ていねい（3時間）を打つと、10:00 → 13:00
- 12:00をまたぐときは、昼休みを挟んで表示する
- 17:00になると日が暮れて、お客さんが来て、また朝8:00

**説明を読まなくても、1日が何なのか分かります。**

設備もそのまま効きます。

| 設備 | いま | 時計では |
|---|---|---|
| 夜明け前から手が動かせる | +1時間 | **7:00から**始まる |
| 手元だけを明るく照らす | +2時間 | **19:00まで**やれる |

## 4. 集中力 ── 今日の調子

### 朝、きまる

毎朝ふり直します。**作業では減りません。**

出目は **20〜100**。1〜100ではなく20からにしたのは、
**遊びにならない日を作らないため**です。
まんなかが出やすい山なりにします（20〜100を二回ふって平均）。

| 段 | 出目 | ふつうの工程の品質 | 出かた |
|---|---|---|---|
| **冴えている** | 80〜100 | **×1.15** | 14% |
| ふつう | 60〜79 | ×1.00 | 38% |
| いまひとつ | 40〜59 | ×0.90 | 36% |
| **ぼんやり** | 20〜39 | **×0.80**・しくじりやすい | 12% |

**数字ではなく、言葉で出します。**「🕯 冴えている 88」。
読むのは言葉のほうで、数字は添えもの。

朝、KoBoさんがひとこと言います。

> 🌅 6日目の朝じゃ。きょうは手がよう動くぞ。（冴えている 88）
> 🌅 6日目の朝じゃ。……どうも、ぼんやりしておるな。（ぼんやり 31）

**ここが、ランダムがいちばん楽しい瞬間**です。隠さずに見せます。

### 効くところ、効かないところ

| | |
|---|---|
| **効く** | ふつうの工程でもらえる品質。しくじりやすさ |
| **効かない** | **山場（ミニゲーム）の点** |

**これが大事です。**自分が今まさに遊んでいるミニゲームの点が
さいころで上下すると、うまくやっても報われない感じになります。

流れは**一方通行**にします。

```
   腕（ミニゲームの出来）  →  調子  →  ふつうの工程の出来
```

ミニゲームが調子を動かし、調子がふつうの工程に効く。逆流しません。

### 一台ぶんで、どれくらい効くか

ていねい5工程（1工程14点）で作った場合。

| | 5工程ぶん | ふつうとの差 |
|---|---|---|
| 冴えている | 80点 | **+10** |
| ふつう | 70点 | — |
| いまひとつ | 63点 | −7 |
| ぼんやり | 56点 | **−14** |

階級のしきいは **S:90／A:75／B:60**。
**調子ひとつで、だいたい階級ひとつぶん動きます。**
効いているのは分かるが、台無しにはならない。ちょうどいい幅です。

### 何で動くか

**① ミニゲームの出来**（終わったときに動く）

| 山場の点 | 調子 |
|---|---|
| 90以上 | **+12**　乗ってきた |
| 70〜89 | **+5** |
| 45〜69 | 0 |
| 45未満 | **−8** |

**上がるほうを厚く、下がるほうを薄く**しています。

ミニゲームで失敗すると、もうその一台の品質は下がっています。
そこに調子の低下まで重ねると、**一度の失敗が後まで尾を引いて**
立て直せなくなります。催しで初めて触る方には、きつすぎます。

下限は **10**。どれだけ失敗しても、そこで止まります。

**② おいしいもの**（静岡の名品。いまのまま使えます）

| | |
|---|---|
| 🍊 みかん | +12 |
| 🍵 お茶 | +25 |
| 🐟 しらす丼 | +45 |
| 🍢 おでん | +20 と 作業時間+1 |

**ここは一行も変えません。**
「ぼんやりした日に、みかんを剥く」── 意味がそのまま通ります。
むしろ、**いまより役に立つ**ようになります。
（上限は100。満ちているときは使えない、もいまのまま）

**③ 設備 ── 悪い日を減らす**

集中力の設備は、上限を上げるのをやめて、**朝の出目の下限**を上げます。

| 設備 | いま | 変えたあと | ぼんやりの出かた |
|---|---|---|---|
| なし | — | 下限20 | 12% |
| 賄い付き | 集中+20 | **下限35** | **1%** |
| ＋丁稚 | 集中+30 | **下限45** | **0%** |

**あたたかい昼飯と、手伝ってくれる丁稚がいれば、ひどい日は来ない。**
意味が通りますし、数字でもちゃんと効いています。

**④ 研ぎたての刃**

いまは「集中力−20」。そのまま残します。
**切れ味は上がるが、気を使う**（+12%の代わりに調子−20）。
調子の仕組みができたので、ここで初めて本当の判断になります。

## 5. 気をつけたこと

### ① はじめての一日は、必ず良い日にする

催しでは、ひとり **15分ほど**しか遊びません。
**最初の日が「ぼんやり」だと、それがその方のゲームの印象すべて**になります。

**1日目は 85〜100 で固定**します。2日目からふり始めます。

### ② 悪い日を、損ではなく「手の打ちどころ」にする

ぼんやりの日こそ、

- みかんを剥く（+12）
- その日は**手早く**で数をこなして、ていねいは明日に回す
- 山場で90点を出して、+12で持ち直す

**打つ手がある**なら、悪い日は嫌なものではなくなります。
この三つが全部あるので、成立します。

### ③ 幅を広げすぎない

1〜100でそのまま掛けると、良い日と悪い日で**2倍**ひらきます。
納期の決まったこのゲームでは、それは事故です。

**四段に丸めて、±15%に収めました。**
読むのも「冴えている／ぼんやり」の言葉だけで済みます。

---

## 6. セーブ

**壊れません。**

`state.focus` はそのまま使います（意味だけが「持ち分」から「今日の調子」に変わる）。
古いセーブの値はそのまま読み、**翌朝からふり直し**になります。
移行の手当ては要りません。

| | いま | 変えたあと |

## 8. 決めていただきたいこと

1. **この形で進めてよいか**
2. **朝の出目の幅**　20〜100でよいか（もっと荒くしたい／穏やかにしたい）
3. **効き幅**　±15%でよいか（もっと効かせたい／もっと軽く）
4. **翌朝への持ち越し**
   いまの案では、前日どれだけ調子を上げても翌朝はまっさらです。
   「昨日が良かった日は、翌朝の下限が少し上がる」を足すこともできます。
   **分かりにくくなるので、まずは無しを勧めます。**
