# 三つの手が、選択になっていない

> 「木目を読む他2つの意味合いが薄くなっている。
>  時間がたっぷりあるのでいつも一番左の一番いい状態を選べてしまう。」

おっしゃるとおりでした。しかも、**理由は二つ**あります。
どちらも数字で出ます。まだ実装はしていません。

---

## 1. ていねいは「高い手」ではなく、ただの「一番得な手」だった

工程ごとに、**時間あたりどれだけ品質が増えるか**を計算しました。
（期待値 ＝ もらえる品質 − しくじり率 × 8）

| 工程 | 手 | 時間 | 期待値 | **1時間あたり** |
|---|---|---|---|---|
| 木取り | 木目を読む | 3h | 12.8 | **4.27** |
| | 素直に取る | 2h | 6.6 | 3.30 |
| | 歩留まり優先 | 1h | 0.8 | 0.80 |
| 研磨 | 番手を上げる | 3h | 13.8 | **4.61** |
| | ひととおり | 2h | 6.6 | 3.30 |
| | ざっと当てる | 1h | 1.0 | 1.00 |
| 彫刻 | 彫り込む | 3h | 15.2 | **5.07** |
| | 控えめに | 2h | 7.4 | 3.68 |
| | 型どおり | 1h | 1.4 | 1.40 |
| 張り | しわなく張る | 3h | 13.6 | **4.53** |
| | ふつうに張る | 2h | 6.4 | 3.18 |
| | 留めるだけ | 1h | 0.0 | **0.00** |

**ていねいが、時間あたりでも一番得をしています。**

これは「高いが良い手」ではありません。**安いほうを選ぶ理由が、どこにもない**ということです。
時間が余っているかぎり、考える余地はありません。

とくに「留めるだけ」は期待値 **0.0**。しくじりの分で、もらえる品質が丸ごと消えます。
**押してはいけないボタン**が、選択肢の顔をして並んでいました。

### しくじり率が、逆になっている所もあります

| 工程 | ていねい | ふつう |
|---|---|---|
| 木取り | **0.15** | 0.05 |
| 彫刻 | **0.10** | 0.08 |

**ていねいにやるほど、手がすべりやすい。**ここは単純な入れちがいだと思います。

---

## 2. 第二工房を買った瞬間に、納期が効かなくなる

設備「第二工房」（25,000円）と「第三工房」は、**全工程の時間を −1時間**します。

| 設備 | ぜんぶ「ていねい」で納期に間に合う家具 |
|---|---|
| なし | **2 / 23 件** |
| 第二工房（−1h） | **23 / 23 件** |
| ＋第三工房（−2h） | 23 / 23 件（半分の時間で終わる） |

例：ドクロのキャビネット（工程6・納期16h）

```
設備なし   ぜんぶていねい 18h  →  納期まで −2h   間に合わない
第二工房   ぜんぶていねい 12h  →  納期まで +4h   間に合う
第三工房   ぜんぶていねい  6h  →  納期まで +10h  余りまくる
```

**設備を買う前は、ちゃんと選択になっていました。**買った瞬間に消えます。

### もっと悪いことが起きています

時間の計算が **引き算** です。

```
effHours = max(1, その手の時間 − 設備の短縮)
```

引き算は、**差そのものを潰します**。

| 設備 | ていねい | ふつう | 手早く | 何が起きるか |
|---|---|---|---|---|
| なし | 3h | 2h | 1h | 三つとも別の値段 |
| −1h | 2h | **1h** | **1h** | ふつうと手早くが同じ値段。**手早くは完全に無駄** |
| −2h | **1h** | **1h** | **1h** | 三つとも同じ値段。**選択が消える** |

お送りいただいた画面が、まさにこれでした（2時間／1時間／1時間）。
**ふつうと手早くが同じ値段で、品質だけ違う。**選ぶまでもありません。

---

## 3. 直しかた（案）

### ① 設備の「引き算」をやめる

第二工房・第三工房の **−1時間／工程** を廃止し、別の効きかたにします。

> **助っ人が下ごしらえをしておいてくれる**
> → **一台につき、最初の工程が１つただになる**（第三工房でもう１つ）

効き目は同じくらい（一台あたり2〜3時間の節約）ですが、
**手の値段差はそのまま残ります**。選択が消えません。

### ② ていねいを「総量は一番、効率は一番下」にする

いまは「一番いいうえに一番効率もいい」。これを、
**ていねい＝たくさん積めるが割高／手早く＝安いが少し**に直します。

| | いま | 変えたあと | 1時間あたり |
|---|---|---|---|
| ていねい | 3h・q14 | 3h・**q14**（据え置き） | 4.67 |
| ふつう | 2h・q7 | 2h・**q10** | 5.00 |
| 手早く | 1h・q2 | 1h・**q6** | 6.00 |

**上限は動きません。**ぜんぶていねいで積める35点は、いまのままです。
変わるのは、**時間が足りないときに手早くを選ぶ理由ができる**ことだけです。

「留めるだけ」の期待値 0.0 も、これで 4.0 になります。

### ③ しくじり率の逆転を直す

どの工程でも **ていねい ≦ ふつう ≦ 手早く** にそろえます。

### ④ ボタンに、時間以外のことも書く

いまボタンに出ているのは **⏱時間だけ**です。
しくじりやすさも、材料が戻ることも、押すまで分かりません。

```
👁 木目を読む        🙂 素直に取る        💨 歩留まり優先
⏱3時間              ⏱2時間              ⏱1時間
仕上がり ◎           仕上がり ○           仕上がり △
                                        🪵 材料が戻ることがある
```

※「歩留まり優先」には、もともと **25%で木材が1本戻る**しくみが入っています。
　画面に出ていないので、誰も気づけません。

---

## 4. ①だけでも効きます

もし小さく済ませたいなら、**①（設備の引き算をやめる）だけ**でも、
設備を買ったあとの「いつも一番左」は直ります。

ただし設備なしでも **ていねいが時間あたり一番得**なのは変わらないので、
「納期に間に合う範囲で、できるだけ左を押す」という作業にはなります。
**②まで入れて、はじめて"選ぶ"ことになります。**

---

## 5. 決めていただきたいこと

1. **どこまでやるか**
   - ①だけ（設備の直しのみ・影響が小さい）
   - ①＋②＋③（選択として成立させる）
   - ①〜④（ボタンの表示まで）
2. **②の数字でよいか**（ふつう 7→10、手早く 2→6）
3. **第二工房の効きかた**「最初の工程が１つただ」で違和感がないか

セーブは壊れません。どの案も、数字と表示を変えるだけです。
