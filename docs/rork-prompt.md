# Rork 用 一発生成プロンプト（用宗シラス漁ものがたり）

Rork（React Native + Expo 系のAIアプリビルダー）にそのまま貼り付けて使う指示文。
アートも生成に任せる想定。長さ制限がある場合は【】ブロック単位で削って調整。

---

「用宗シラス漁ものがたり」というスマホ向け・縦持ちの放置経営ゲームを作って。React Native + Expo、縦画面固定、タッチ操作、なめらかな60fps。静岡・用宗漁港が舞台で、しらす漁→加工→販売の経営を「手運び」から「自動化」へ育てていく。アセット（キャラ・建物・アイコン・背景）も全部、下記の画風で生成して。

【画風・アート】
- 2頭身のちびキャラ＆ミニチュア風。温かいセル＋淡い水彩の手描きアニメ調。均一な茶系の輪郭線、柔らかい光。全アセットを同じ画風・同じ光源で統一。
- 世界観は富士山が見える用宗漁港。漁師キャラ（白いハチマキ・青いつなぎ・黄色いサスペンダー・緑の長靴）。しらすは「バケツの生しらす／パック詰め／しらす丼」。建物は加工場・直売所・しらす食堂。お客さん数種、シラスの群れ（小・大）、漁船（小型・大型）。
- 漁師は4方向の歩行アニメ（前・後・左・右、各2〜4コマ）。

【画面構成：縦スクロールのワンマップ（カメラがキャラを追従）】
- 上：⭐大漁場（魚が多い。大型船にすると入れる）
- 中：🌊通常の海（漁船が浮かぶ）
- 下：陸＝🪣水揚げ場／🏭加工場／🏪直売所／🍚食堂 と、👨‍👩‍👧‍👦お客さんの行列
- 上部HUD：所持金／「売上◯円/秒」／手持ち（積み荷）／評判／日数

【基本操作とループ】
- 画面を指でドラッグして漁師を移動（加減速のイージング＋方向別の歩行アニメ）。
- 海で泳ぐ「シラスの群れ」に重なると生しらすを獲得（手持ちにバケツが積み上がる。大漁場の大きな群れは2倍）。
- 生しらすを🪣水揚げ場へ運んで降ろす→🏭加工場へ運ぶと「加工しらす（パック）」になる。
- 加工しらすを🏪直売所へ運ぶとパックで販売、🍚食堂へ運ぶと「しらす丼」に調理して販売（食堂は単価が高い）。
- お客さんが行列に並び、カウンターで支払い（コインが飛ぶ）→商品を受け取って退店→売上に。店頭には商品（丼）が並ぶ。
- 拠点に立つと、手持ちを自動で荷降ろし／完成品を自動で積み込み。

【自動化の育成（放置ゲームの肝：手運び→自動化）】
- Lv1 手運び：全部プレイヤーが運ぶ完全移動ゲー。
- Lv2 ベルトコンベア：水揚げ場→加工場を自動搬送。
- Lv3 軽トラック：加工場→直売所/食堂を自動搬送。
- Lv4 販売員NPC＋集客：販売が自動化・客が増える・売上倍率アップ。
- Lv5 完全自動化：漁船が自動操業（海→水揚げ場も自動）。全自動になり、プレイヤーは設備強化に専念。

【アップグレード（お金で購入）】
- 漁船：移動速度・積載量アップ／Lv3で大漁場解放／魚の群れ増加
- 水揚げ場・加工場・食堂：処理速度・保管量アップ
- 直売所：客数・売値アップ
- 各自動化設備（コンベア／軽トラック／販売員NPC／自動操業）とそのレベル

【経済・数値（初期の目安、要バランス調整）】
- 直売所パック 約120円〜（安い・回転速い）、食堂の丼 約350円〜（高単価・調理時間あり）。
- 評判は販売で少しずつ上昇、クレームで低下し客足に影響。
- 「売上◯円/秒」を常時表示。序盤は直売所だけ、約3,000円で食堂を解放する拡張要素に。

【オフライン収益（放置）】
- アプリを閉じている間も、自動化済みの区間だけが稼働して売上が貯まる。手運びが残る区間で止まる（＝自動化するほど放置で稼げる）。最大数時間でキャップ。復帰時に「留守中に◯◯円 稼ぎました！」モーダル。

【ランダムイベント】
- マイナス：加工機の故障（修理費 or 待って自力修理）、不漁（魚が減る）、クレーム（評判低下・謝罪で回復）。
- プラス：大漁の群れ（漁獲2倍）、観光バス到着（客急増）。

【演出・仕上げ】
- 方向別の歩行アニメ、船の上下＆左右の揺れ、海の多層の波＋きらめき＋岸の泡、獲得/納品/売上のパーティクル、支払いのコイン、丼が店から客へ飛ぶ受け取り演出。効果音（漁・納品・売上・レベルアップ）とBGMがあれば尚良い。

【その他】
- 進行はローカル保存（自動セーブ・オフライン復帰対応）。UIテキストは日本語。
- タイトル画面に「はじめる」「最初からやり直す」「あそびかた」。

まずは直売所ルートだけで最後まで遊べる形（漁→水揚げ→加工→直売→売上→アップグレード）を必ず動くように作り、食堂・自動化・オフライン収益・イベントは段階的に足してOK。とにかく「指でキャラを動かして運び、貯めたお金で自動化して放置でも稼げる」体験を一番大事に。
