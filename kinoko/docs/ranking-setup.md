# 見にきてくれた人を数える ／ ゲームのランキングを作る

このサイトは GitHub Pages という「置くだけ」の場所で動いているので、
そのままでは **人数を数えたり、みんなの記録を保存したり** ができません。
Google スプレッドシートを「小さなサーバー」として使うと、無料でできます。

- お金はかかりません
- 保存先は **あなた自身の Google ドライブ** です。ほかの会社には何も渡りません
- 記録するのは **表示回数と、ゲームの名前・点数だけ**。
  住所やIPアドレス、だれが見たかは記録しません

作業はぜんぶで **10分ほど**。1回やれば、あとはずっと動きます。

---

## 1. スプレッドシートを作る

1. パソコンかスマホで https://sheets.new を開く（Google にログインした状態で）
2. できた表の左上の名前を **「イワオトキノコ 記録」** に変える
3. そのまま閉じずに次へ

## 2. スクリプトを貼り付ける

1. 上のメニューから **拡張機能 → Apps Script** を開く
2. 出てきた画面に最初から書いてある `function myFunction() {...}` を **全部消す**
3. この中身を **まるごとコピーして貼り付ける**
   → `kinoko/apps-script/Code.gs`
   （GitHub でファイルを開いて、右上のコピーボタンでもOK）
4. 左上の **フロッピーのマーク（保存）** を押す

## 3. ウェブアプリとして公開する

1. 右上の **デプロイ → 新しいデプロイ** を押す
2. 歯車マーク ⚙ → **ウェブアプリ** を選ぶ
3. 次のように設定する
   - 説明：`イワオトキノコ`（なんでもよい）
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**  ← ここが大事です
4. **デプロイ** を押す
5. 「承認が必要です」と出たら → **アクセスを承認** → 自分の Google アカウントを選ぶ
   - 「このアプリは確認されていません」と出たら、
     **詳細 → （安全ではないページ）に移動** を押す。自分で作ったものなので大丈夫です
6. 最後に出る **ウェブアプリのURL** をコピーする
   （`https://script.google.com/macros/s/……/exec` という形）

## 4. サイトにURLを教える

`kinoko/web/data/config.json` を開いて、`apiUrl` にそのURLを貼ります。

```json
{
  "apiUrl": "https://script.google.com/macros/s/ここがあなたのURL/exec",
  "showVisits": false
}
```

GitHub の画面から直接なおせます。

1. https://github.com/KijibuKoBo/-/blob/main/kinoko/web/data/config.json を開く
2. 鉛筆マーク ✏ を押す
3. `"apiUrl": ""` の `""` の中にURLを貼る
4. 下の **Commit changes** を押す

1〜2分待つと、サイトに反映されます。

---

## できるようになること

### 見にきた人の数
- サイトのどのページを何回開かれたかを、日ごとに数えます
- **サイトには表示されません。**
  管理画面（`admin.html`）の **「📊 みんなの記録」** タブでだけ見られます

### ゲームのランキング
- 「きのこマッチパズル」と「きのこつみ」で **ベスト5** を表示します
- 5位以内に入ると、終わった画面で **なまえを登録** できます（12文字まで）
- 管理画面から、ふさわしくない名前を **消す** ことができます

## 気をつけること

- 誰でも登録できる仕組みなので、**うその点数を入れる人がいる可能性はゼロではありません**。
  家族や知り合いに見てもらうぶんには十分ですが、賞品を出すような使い方には向きません。
  おかしな記録は管理画面から消してください。
- 管理画面で集計を見るための合言葉は、`Code.gs` の `ADMIN_KEY` に書いてあります（初期値 `100`）。
  変えるときは `Code.gs` と `admin.js` の両方を合わせてください。
- スクリプトを直したら、そのつど **デプロイ → デプロイを管理 → 鉛筆マーク → バージョン：新バージョン → デプロイ**
  をしてください。URLは変わりません。

## うまくいかないとき

| 症状 | 見るところ |
|---|---|
| ランキングが出てこない | `config.json` のURLの終わりが `/exec` になっているか |
| 「集計を読み込めませんでした」 | 手順3の「アクセスできるユーザー：**全員**」になっているか |
| 数字が増えない | ブラウザの「シークレットウィンドウ」で開いて試す（広告ブロックが邪魔していることがあります） |
