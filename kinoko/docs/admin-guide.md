# 管理ページの使い方（パスワード 100 でできること）

`web/admin.html` を開くと、ホームページの中身を直接編集できます。
「公開」ボタンを押すと GitHub に保存され、**1〜2分**でホームページに反映されます。

> 巖さん向けの図入り説明書は **[`web/guide.pdf`](../web/guide.pdf)**（A4・11ページ）です。
> 管理ページのログイン画面と見出しからも開けます。
> このファイルは `tools/shots.py` → `tools/make-guide.py` で作り直せます（下記）。

---

## パスワードは2つ

| パスワード | できること |
|---|---|
| **100** | 🍄 キノコ・📝 コラム・📔 日誌・📊 みんなの記録・📬 投稿。**🛍 グッズのタブは出ません** |
| **314** | 上のぜんぶ ＋ 🛍 グッズ |

ログインすると右上に「グッズ以外を編集できます／すべて編集できます」と出ます。
となりの **🔒 ログアウト** で入力画面に戻り、もう一方のパスワードで入り直せます。

> Google スプレッドシート（Apps Script）へ送る鍵は、どちらでログインしても `100` のまま。
> `apps-script/Code.gs` 側は `100` と `314` のどちらも受け付けますが、貼り直さなくても動きます。

**この URL と2つのパスワードは共有しないこと。** ページは `noindex` にしてあります。

---

## 最初に1回だけ：GitHubトークンの登録

「公開」が GitHub に書き込むための鍵です。**端末（ブラウザ）ごとに1回**必要で、
その端末の localStorage にだけ保存され、外には送られません。

1. GitHub の [Fine-grained トークン発行ページ](https://github.com/settings/tokens?type=beta) を開く
2. **Generate new token**
   - Repository access → **Only select repositories** → `KijibuKoBo/-`
   - Permissions → Repository permissions の **Contents** を **Read and write**
3. 出てきた `github_pat_…` をコピー（この画面でしか見られません）
4. 管理ページ右上の **⚙ 設定** に貼り付け
   - オーナー `KijibuKoBo` ／ リポジトリ `-` ／ ブランチ `main`
5. **接続テスト** → 「✓ 接続OK」→ **設定を保存**

鍵が無いと、公開時に「先に ⚙設定 で GitHub トークンを登録してください」と出ます。

## 🍄 キノコ

### 追加する
1. 「編集する記録」が **＋ 新しいキノコを追加** になっているか確認
2. **和名・食毒・採集日**（赤い ＊）は必須。他は空でよい
3. **📷 写真を追加**（複数可・自動で圧縮される）
   - `◀ ▶` 並べ替え／`主` メイン写真に指定／`🗑` 外す
   - いちばん左（1枚目）がトップ・図鑑に出るメイン写真
4. **👁 プレビュー** で確認 → **🍄 公開する** → 「✅ 公開しました」

### 直す・消す
- 「編集する記録」から選ぶとフォームに入る → 直して **公開する**
- 写真を選び直さなければ、写真は元のまま
- 選んだ状態で下に出る **🗑 この記録を消す** → 確認 → 削除（戻せない）

> ⚠ 他の記録を選んだまま公開すると、**その記録が上書き**される。
> 新規は必ず「＋ 新しい…」を選んでから。

## 📝 コラム
やり方はキノコと同じ。**題名**が必須、写真は1枚まで。本文は**空行で段落**が分かれる。

## 📔 日誌
日付（初期値は今日）・場所・キノコ名を入れて **公開する**。下の一覧から1件ずつ消せる。

## 📊 みんなの記録（閲覧のみ）
表示回数・だいたいの人数・日ごと/ページごとの内訳と、ゲームのランキング。
ふさわしくない名前は「消す」で削除できる。**この画面でしか見られず、サイトには出していない。**

## 📬 投稿（「このキノコ なに？」）
- 送られてきた写真は **「✓ 公開する」を押すまでサイトに出ない**
- `↩ 下げる`（非公開に戻す）／`🗑 消す`（写真ごと削除・戻せない）
- 下の欄に書いて「答える」で、**「採集者」の印つき**のコメントが載る
- 答えるときは「食べてよい」と断定しない書き方で

## うまくいかない時

| 症状 | 対処 |
|---|---|
| 「パスワードが違います」 | 半角数字か確認（かな入力になっていないか） |
| 「先に ⚙設定 で GitHub トークンを登録してください」 | ⚙設定で鍵を入れる。端末ごとに必要 |
| 「✗ 公開に失敗」 | 電波のよい場所で再試行。続くならトークンの期限切れを疑う |
| 公開したのに反映されない | 1〜2分待ってリロード |
| 📊 📬 が「まだ準備ができていません」 | Apps Script 未接続。`docs/ranking-setup.md` 参照 |

## 説明書（PDF）を作り直す

```bash
cd kinoko/web && python3 -m http.server 8899 &     # ローカルで配信
cd kinoko
python3 tools/shots.py /tmp/shots                   # 画面写真を撮る
python3 tools/make-guide.py /tmp/shots web/guide.pdf
```

- `tools/shots.py` … 管理ページを実際に操作して図を撮る。
  📊📬 は Apps Script に繋がっていないと中身が出ないので、**見本データ**を流し込んでいる。
- `tools/make-guide.py` … 図を埋め込んだ A4 の HTML を組み立て、Chromium で PDF 化する。
  文面はこのファイルの中（`BODY`）にある。
