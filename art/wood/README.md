# 木材の絵

松永工房さんが描いた木材の絵と、それを切り出す道具です。
ゲーム本体（`game/index.html`）には、できあがった絵が `WOOD_ART` として
WebP で埋めこまれています。**ここにあるのは、作り直すときのための控えです。**

---

## 中身

| | |
|---|---|
| `sheets/` | いただいた絵のシート1枚。市松の背景だけ抜いて、透過にしてあります |
| `parts/` | 切り出した7種。長いほうを180ピクセルにそろえてあります |
| `tools/` | 切り出しに使った道具（Python） |

## いま入っている7種

序章で使える木材です。葉や実、松ぼっくり、桜の花も絵のうちなので、
まとめて1枚に収めてあります。

| | |
|---|---|
| パイン | 松ぼっくりと松葉 |
| ブナ | 葉 |
| 栗 | いがと実 |
| オーク | 葉 |
| チェリー | 桜の花 |
| メープル | もみじの葉 |
| ウォールナット | 葉 |

**第二章・第三章の5種（マホガニー・チーク・ローズウッド・黒檀・神代欅）は、
まだ絵がありません。**記号のまま出ます。絵ができたら `parts/` に足して、
下の手順で作り直せば、そのまま入ります。

---

## どうやって切り出したか

### 1. 市松の背景を抜く（`key.py`）

市松は「中くらいの明るさ・無彩色・**細かく明暗が交互する**」。
三つ目が効いていて、絵の中の白っぽい所（ブナやメープルの木肌）は残ります。

### 2. 丸太のかたまりを拾う（`woodcut.py`）

抜いたあとに残るのは、丸太7つと、見出しの札と、説明の文字です。
丸太だけが飛びぬけて大きい（2万画素以上）ので、そこで選り分けます。

葉や実は丸太にくっついているので、**ひとつながりのかたまりとして一緒に取れます。**
となりの文字が角に入らないよう、そのかたまりの形だけを残しています。

### 3. 大きさをそろえて詰める

長いほうを180ピクセルにそろえ、WebP（画質80）にします。7種で **65KB** です。

---

## 作り直すとき

```bash
cd art/wood/tools
python3 key.py ../sheets/木材7種.webp   # シートを差しかえたとき
python3 woodcut.py                      # 切り出して wood-art.js を書き出す
```

できた `wood-art.js` を `game/index.html` の `const WOOD_ART = {…}` と入れかえます。
Pillow・numpy・scipy が要ります。

---

## 絵を足すとき

`woodcut.py` の **`IDS`** に、`MATERIALS` と同じ id を並び順どおりに書きます。
シートの並び（上の行を左から、次に下の行を左から）と合わせてください。

ゲーム側は `WOOD_ART` に id があるかどうかだけを見ています。
**絵がなければ、これまでどおり記号で出ます。**一覧をいじる必要はありません。

絵は**丸太を横ぎみに置いて、右下あたりに葉や実をそえる**と、
ならべたときに高さがそろって気持ちよく見えます。
