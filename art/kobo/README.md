# KoBoさんの四面図

松永工房さんが用意された、案内役 KoBoさんの四方からの絵です。
ゲーム本体（`game/index.html`）には、できあがった絵が `PHOTOS` の
`kobo_body` / `kobo_body_r` / `kobo_body_b` / `kobo_body_l` として
WebP で埋めこまれています。**ここにあるのは、作り直すときのための控えです。**

---

## 中身

| | |
|---|---|
| `sheet.png` | いただいた四面図（1536×1024） |
| `front.png` | 正面 → `kobo_body` |
| `sideR.png` | 右向き → `kobo_body_r` |
| `back.png` | 後ろ → `kobo_body_b` |
| `sideL.png` | 左向き → `kobo_body_l` |
| `cut.py` | 切り出しの道具 |

**横顔2枚は、鏡像ではありません。**左右で光の当たりかたがちがう、
別々の絵です（返して重ねると色の差が28ほど出ます）。
なので「左右反転」では代用せず、4枚とも持っています。

背たけはどれも300pxにそろえてあります。4枚で **55KB**。

---

## どうやって切り出したか

背景は**暗い緑〜茶のぼかし**で、人物のまわりには明るいかさ（グロー）が出ています。

一色を決めて抜こうとすると、**かさの明るさに引きずられて、白いひげまで食います。**
実際、最初はあごひげの右側がごっそり消えました。

そこで「**ふちから、となりと色が近いうちだけ広がる**」やり方で抜いています。
ぼかしはとなり同士が似ているので通りぬけ、絵の輪郭で止まります。

**しきい値は 4 です。**6 だとひげを食い、3 以下だとかさが残ります。

```bash
cd art/kobo
python3 -I cut.py 4
```

できた4枚を WebP（画質86）にして、`PHOTOS` と入れかえます。
Pillow・numpy・scipy が要ります。

## ゲームでの使われかた

| | |
|---|---|
| ヘッダーの顔 | `kobo_face` / `kobo_back`（**別の絵。ここでは差しかえていません**） |
| 物語のポップアップ、Petit.Continue のページ | `kobo_body`（正面） |
| ドールハウスの見本 | 四方ぜんぶ。**「↻ 向き」で 正面→右→後ろ→左 とまわります** |

向きは置いたものの `p`（0〜3）に残ります。
向きのあるものだけ、操作バーに「↻ 向き」が出ます。

```js
const KOBO_POSES = ["kobo_body", "kobo_body_r", "kobo_body_b", "kobo_body_l"];
```

ほかの人形に向きを持たせたいときは、`poses` に絵をならべるだけです。
ゲーム側は `poses` があるかどうかしか見ていません。
