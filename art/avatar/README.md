# 職人の似顔絵のもとの絵

松永工房さんが描いた似顔絵の絵と、それをゲームの部品に切り分ける道具です。
ゲーム本体（`game/index.html`）には、できあがった部品が WebP で埋めこまれています。
**ここにあるのは、作り直すときのための控えです。**

---

## 中身

| | |
|---|---|
| `sheets/` | いただいた絵のシート4枚。市松の背景だけ抜いて、透過にしてあります |
| `parts/` | シートから切り出した部品48点。280×340 の座標にそろえてあります |
| `tools/` | 切り出しに使った道具（Python） |

### シート4枚

| シート | 中身 |
|---|---|
| 1 | 髪型20種（男性10・女性10）。**ゲームの「頭」はこれを使っています** |
| 2 | 既定の顔／髪型10種／目5種／口5種。**目と口はこれを使っています** |
| 3 | 既定の顔／メガネ3種／ピアス3種／ひげ3種 |
| 4 | 被り物10種（1番目は「なし」） |

シート2の髪型10種は、シート1より小さく描かれていて粗くなるので使っていません。

---

## どうやって切り出したか

絵はどれも「顔の上に部品が乗った一枚絵」なので、そのままでは重ねられません。
次の順で、重ねられる部品にほどいています。

### 1. 市松の背景を抜く（`key.py`）

市松は「中くらいの明るさ・無彩色・細かく明暗が交互する」。
この三つ目が効いていて、**サンタ帽の白いふちやウサ耳のような「絵の中の白」は残ります**。

### 2. 顔を見つける（`faces.py` / `faces2.py`）

どの顔にも、桃色の丸が「ほお・鼻・ほお」と決まった形でならんでいます。
これを手がかりにすると、見出しの札も、ウサ耳の**耳の内側の桃色**もまぎれこみません。

見つけたほお2つを基準に、**ほおとほおの間を100ピクセル**、
ほおの中点を決まった位置に置いて切り出すので、どのコマも同じ大きさ・同じ位置になります。
枠ではなく「ほおからの決まった窓」で切るので、下にある札は入りません。

> メガネはブリッジが鼻にかかって鼻の丸が消えます。そのときだけ、
> 「コマのまんなかに対して左右対称な組」をほおとみなす受け皿が働きます。

### 3. 部品に分ける（`build2.py`）

位置がそろっているので、**顔のどのあたりか**で取り分けられます。
輪郭の1ピクセルのずれに振り回されません。

| 部品 | 取り方 |
|---|---|
| 頭 | シート1のコマを、顔とひとつながりの所だけ残して、そのまま使う |
| 目・口 | 既定の目と口を**肌ごと四角で隠し**、まゆなどはみ出すぶんは形に沿って抜く |
| メガネ・ピアス・ひげ | 既定の顔との差。髪の所の差は無視して、置かれる場所に絞る |
| 被り物 | 「なし」のコマとの差。細い線は落とし、**細かな抜けだけ**をふさぐ（フードの内側は開けたまま） |

### 4. 詰める（`export.py`）

256×256 にそろえ、縁を落として WebP（画質74）にし、
`AV_ART`（名前 →「左・上・中身」）という一行にします。48点で **179KB** です。

枠の大きさは「頭（髪＋顔）の広がり」に合わせてあります。横256は、いちばん広い髪型
（くるくる）でちょうど。縦は頭の広がりを真ん中に置くと、帽子がうまく上いっぱいに収まります。
**ウサ耳だけは、はみ出したぶんが切れます。**耳のために枠を広げると、
そのぶん全部の顔が小さく下に寄ってしまうので、切れるほうを選んでいます。

## 作り直すとき

```bash
cd art/avatar/tools
python3 key.py ../sheets/*.webp      # 市松を抜く（シートを差しかえたとき）
python3 build2.py                    # 部品に分ける
python3 export.py                    # av-art.js を書き出す
```

できた `av-art.js` を `game/index.html` の `const AV_ART = {…}` と入れかえます。
Pillow・numpy・scipy が要ります。

## 絵を足すとき

**番号はセーブデータに残ります。**途中に差しこむと、
前に作った職人の顔が勝手に変わってしまいます。かならず**うしろに足して**ください。

1. `parts/` に 280×340 の座標でそろえた絵を置く
2. `export.py` の `ORDER` に名前を足して書き出す
3. `game/index.html` の `AV_HAIR` などの一覧に1行足す

髪の色と肌の色の塗りかえは、絵の明暗をそのままにした掛け算です。
**髪は黒っぽく（明るさ140未満）、肌は明るく赤みのある色**で描いてください。
帽子やめがねは塗りかえの対象外なので、好きな色で構いません。
