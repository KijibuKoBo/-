# 松永工房クラフトストーリー
### 〜小さな家具と、届かなかった手紙〜

スマホのブラウザで遊べる、家具づくりのコレクションゲームです。
プレイヤーは有限会社松永工房の新人職人。**家具図鑑をぜんぶ埋めること**が目的です。

HTML1ファイルだけでできています。外部ライブラリなし、通信なし、インストール不要。

---

## 遊びの流れ

```
設計図をえらぶ
  ↓
材料を仕入れる
  ↓
どう作るか決める（設計・素材・仕上げ）
  ↓
工程ごとに判断しながら作る
  ↓
図鑑に登録される
  ↓
納品する（すぐお金）／展示する（毎日の来館収入）
  ↓
お金と来館者が増える
  ↓
新しい設計図が解放される
  ↓
また一台つくりたくなる
```

## どう作るかを決める

制作前に3つ選びます。この組み合わせで品質・人気・値段が変わります。

**設計**
- クラシック … 品質+5・人気+5
- 豪華 … 人気+10・値段+20%（木材を1本多く使う）
- 小型 … 人気+5・値段−10%

**素材（木材）**
- ウォールナット 500円 … 品質+5・人気+5・値段+5%
- オーク 350円 … 品質+5
- チェリー 400円 … 人気+8

**仕上げ**
- アンティーク … 人気+10
- ナチュラル … 品質+5
- 漆黒 … 人気+5・値段+15%

材料は「🧺 仕入れ」で買います。足りないと制作を始められません。

## 制作中の判断

ここがゲームの中心です。工程ごとに3つの手から選びます。

**工程によって選べる手が変わります**（8種類）

| 工程 | 選べる手 |
|---|---|
| 木取り | 木目を読む／素直に取る／歩留まり優先 |
| 組立 | 仕口を締める／手順どおり／早く組む |
| 研磨 | 番手を上げる／ひととおり／ざっと当てる |
| 彫刻 | 彫り込む／控えめに／型どおり |
| 張り | しわなく張る／ふつうに張る／留めるだけ |
| 金具 | 面を揃える／取り付ける／手早く留める |
| 塗装 | 重ね塗り／一度塗り／乾かし急ぎ |
| 検品 | 隅々まで／ざっと見る／省く |

**集中力（1日100）**
ていねいな手ほど集中力を食います（30前後）。尽きると、ていねいな手が選べなくなります。「🌙 今日はここまで」で回復できますが、その日の残り時間は納期から引かれます。
→ **全部ていねいには作れません。どの工程に力を注ぐかを選びます。**

**山場工程（🔥）**
家具ごとに1工程だけ、品質の増減が2倍になります。最初はどこか分かりません。1台作ると教えてもらえて、次から図鑑にも記録されます。
→ **遊ぶほど賢くなります。**

**しくじりと修復**
急いだ手はときどき失敗して品質が下がります。最後の検品で「隅々まで」を選ぶと、傷をひとつ見つけて直せます。
→ **失敗しても取り返せます。**

## 品質と値段

品質は100点満点。素材50点からスタートして、選択と工程の判断で増減します。

| ランク | 点数 | 値段 |
|---|---|---|
| S | 90点以上 | ×1.5 |
| A | 75点以上 | ×1.2 |
| B | 60点以上 | ×1.0 |
| C | 60点未満 | ×0.75 |

さらに **納期内なら+10%、遅れると−20%**。設計・素材・仕上げ・設備の倍率も掛かります。

---

## 図鑑（ゲームの目的）

**📖 5 / 11** のように達成率が出ます。各マスに記録されるもの:

- 家具の絵と説明
- 制作回数
- 最高品質ランクと点数
- 人気度
- 山場工程
- その家具の物語

未発見のマスにはヒントだけ出ます。

## 隠し家具（3種）

特定の組み合わせで作ると、隠し家具として図鑑に登録されます。人気+25、値段1.8倍。

見つけ方は3つ。**手紙を読む**（作り方が書いてあります）、**来館者の話を聞く**、**職人手帳の「惜しい」を頼りにする**。3要素のうち2つ合っていると、ヘンリーさんが「なにか惜しい気がするのう」とだけ教えてくれます。

## 展示と来館者

完成した家具は「納品する（すぐお金）」か「展示する（毎日の収入）」を選べます。

展示すると翌日から来館者が来て、売店収入が入ります。展示枠は最初2つ（設備で増やせます）。

**セットボーナス**
- アンティーク仕上げを2点以上 … 収入+20%
- プティ家具（小型）を2点以上 … 収入+15%

**来館者6人**（伯爵・老婦人・若い画家・新婚夫婦・学者・近所の子）が展示を見てひとこと言っていきます。3割の確率で昔の職人の仕事について話し、それが隠し家具のヒントになります。

## 工房を大きくする（設備6種）

| 設備 | 値段 | 効果 |
|---|---|---|
| がっしりした作業台 | 5,000円 | 品質+5 |
| 塗装ブース | 10,000円 | 品質+10 |
| ショールーム増築 | 12,000円 | 展示枠+3 |
| 撮影スペース | 15,000円 | 納品価格+20% |
| 第二工房 | 25,000円 | 全工程の時間−1時間 |
| 海外展示室 | 40,000円 | 来館者+50% |

工房レベルは経験値で上がり、称号が変わります（見習い職人 → 若手職人 → 一人前の職人 → 熟練の職人 → 工房の匠 → 伝説の職人）。

## 物語 ── 届かなかった手紙

家具をはじめて完成させると、その家具の短い物語が読めるようになります。

さらに6つの家具からは**手紙のきれはし**が1枚ずつ見つかります。遠い昔この工房にいた老職人が、若き日のヘンリーさんに宛てて書いた、出せなかった手紙です。

その手紙には、思い出と一緒に**自分の作り方**が書き残されています。

> 「あなたが初めてこの工房に来た日、わたしは小さなカウチを張っておりました。あのときの板は**オーク**。飾り気のない**いちばん素直な形**に組んで、**塗りはかけませんでした**」

読めば作れる。つまり**物語そのものが攻略情報**になっています。

6枚そろうと最終章が解放され、手紙の全文がつながります。

## 自分の職人をつくる

はじめて開くと、自分の職人をこしらえるところから始まります。

髪型6・髪の色6・肌の色4・目4・口4・ひげ3・めがね3・かぶりもの5（手ぬぐい／キャップ／麦わら帽／ニット帽）。十万通り以上の組み合わせがあります。

名前をつけると、案内役のヘンリーさんがその名前で呼んでくれます。

> 「石原 賢、この家具は『彫刻する』が山場じゃったな。覚えておくのじゃぞ」

顔と名前は、ヘッダーの顔をタップすればいつでも作り直せます。

## 案内役・ヘンリーさん

緑のベレー帽に丸めがねの老紳士。工房の家具に惚れこんで、勝手に案内役をしています。

工程を選ぶたび、完成したとき、納品したとき、新しい設計図が解放されたときに声をかけてくれます。工程のあいまには「工房まめ知識」を披露します。

> 「木には『顔』があっての。板の木目を読んで向きを決めるだけで、家具の表情がまるで変わるんじゃ」

## 技術メモ

- `game/index.html` の1ファイルだけで動きます（HTML/CSS/JavaScript、約2,600行）
- 外部ライブラリなし・通信なし・サーバー不要
- イラストはすべてSVG（画像ファイルを持たないので軽い）
- 進行状況はブラウザのlocalStorageに自動保存。遊ぶ人ごとに個別に残ります
- 家具データは配列に分離してあり、1件足すだけで図鑑・設計図・物語がすべて自動で増えます
- 家具データに `photo` 欄を用意済み（将来、実物の写真を図鑑に載せられるようにするため）

**公開するには**
リポジトリの Settings → Pages → Branch を `main` にすると、
`https://kijibukobo.github.io/-/game/` で誰でも遊べるようになります。
アカウント不要・無料・人数制限なし。スマホのホーム画面に追加すればアプリのように起動します。
