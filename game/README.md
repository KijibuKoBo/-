### 〜小さな家具と、いろいろな童話〜

スマホのブラウザで遊べる、家具づくりのコレクションゲームです。
プレイヤーは有限会社松永工房の新人職人。**家具図鑑をぜんぶ埋めること**が目的です。

HTML1ファイルだけでできています。外部ライブラリなし、通信なし、インストール不要。

## どう作るかを決める

制作前に3つ選びます。この組み合わせで品質・人気・値段が変わります。

**設計**
- クラシック … 品質+5・人気+5
- 豪華 … 人気+10・値段+20%（木材を1本多く使う）
- 小型 … 人気+5・値段−10%

**素材（木材）**
- ウォールナット 500円 … 品質+5・人気+5・値段+5%
- オーク 350円 … 品質+5
- チェリー 400円 … 人気+8

**仕上げ**
- アンティーク … 人気+10
- ナチュラル … 品質+5
- 漆黒 … 人気+5・値段+15%

材料は「🧺 仕入れ」で買います。足りないと制作を始められません。

## 制作中の判断

ここがゲームの中心です。工程ごとに3つの手から選びます。

**工程によって選べる手が変わります**（8種類）

| 工程 | 選べる手 |
|---|---|
| 木取り | 木目を読む／素直に取る／歩留まり優先 |
| 組立 | 仕口を締める／手順どおり／早く組む |
| 研磨 | 番手を上げる／ひととおり／ざっと当てる |
| 彫刻 | 彫り込む／控えめに／型どおり |
| 張り | しわなく張る／ふつうに張る／留めるだけ |
| 金具 | 面を揃える／取り付ける／手早く留める |
| 塗装 | 重ね塗り／一度塗り／乾かし急ぎ |
| 検品 | 隅々まで／ざっと見る／省く |

**集中力（1日100）**
ていねいな手ほど集中力を食います（30前後）。尽きると、ていねいな手が選べなくなります。「🌙 今日はここまで」で回復できますが、その日の残り時間は納期から引かれます。
→ **全部ていねいには作れません。どの工程に力を注ぐかを選びます。**

**山場工程（🔥）**
家具ごとに1工程だけ、品質の増減が2倍になります。最初はどこか分かりません。1台作ると教えてもらえて、次から図鑑にも記録されます。
→ **遊ぶほど賢くなります。**

**しくじりと修復**
急いだ手はときどき失敗して品質が下がります。最後の検品で「隅々まで」を選ぶと、傷をひとつ見つけて直せます。
→ **失敗しても取り返せます。**

## 職人アクション ── 山場は自分の手で作る（ミニゲーム10種）

山場の工程だけは、選択肢ではなく**画面を指で操作して**作ります。

10種あって、**どれも単体のゲームとして組んであります**。共通の決まりは3つ。

- **3つの波**がある。進むほど速く、狭く、多くなる
- **連続成功**が伸びるほど点が上がる（命中率8割＋連続2割の配分）
- しくじっても終わらない。ただし**1回につき3点引かれる**

1回およそ25〜40秒。結果は0〜100点で、その点がそのまま最終品質の倍率になります。

| ゲーム | ジャンル | 遊び方 |
|---|---|---|
| **木の目利き** | 落ちもの | 落ちてくる板を受け台で受ける。節のある板は受けてはいけない。金の銘木は2点ぶん |
| **木取り** | 詰めこみパズル | 板から部材を切り出す。節にかからず、重ならない場所を探して置く。波ごとに節が増える |
| **鋸引き** | タイミング | 行き来する鋸が緑の帯に重なった瞬間に押す。帯は 54→40→28 と狭くなる |
| **釘打ち** | リズム（3レーン） | 3列を落ちてくる釘が線に重なった瞬間、その列を叩く。26本 |
| **彫刻** | 一筆なぞり | 下絵を一筆でなぞる。3回続けて彫り、許される太さが 30→24→18 と細くなる |
| **研磨** | 追いかけ | 荒れた所をこすって平らにする。2回で平ら、4回で穴。荒れは**遊んでいる間も増えつづける** |
| **組立** | 形合わせ | 下の部材を選び、合う窪みへ入れる。形と大きさで見分ける。3→4→5個 |
| **布張り** | 方向スワイプ | しわが出たら矢印の向きへ指をはらう。放っておくと癖がつく。輪が時間切れの合図 |
| **金具** | 角度合わせ | ねじのまわりを指でなぞって溝を印に合わせ、離して締める。許される狂いが 20°→14°→9° |
| **塗装** | 量の見きわめ | 面をなでるたびに塗料が乗る。赤い線でちょうど止める。塗りすぎると垂れる |

| 難度 | 対象 | 中身 |
|---|---|---|
| ★☆☆ ふつう | 売値 8,000円未満（15種） | 基準の速さ |
| ★★☆ むずかしい | 8,000〜19,999円（18種） | 速さ・狭さが約1.15倍 |
| ★★★ いちばんむずかしい | 20,000円以上（10種） | 約1.3倍 |

### 道具えらび ── 山場の前の、ひと呼吸ぶんの判断

山場に入る前に、どの道具で挑むか選びます。

| 道具 | 効果 |
|---|---|
| 🔨 いつもの道具 | ふだんどおり |
| ✨ 研ぎたての刃 | 点が**1.12倍**。そのかわり集中力を20よけいに使う |
| 🪵 手になじんだ古い道具 | 点は**0.92倍**。そのかわり**しくじりが出ない** |

残り集中力、この家具の難度、いまのランク目標——そのときどきで答えが変わります。

- 結果は0〜100点。その点が**そのまま最終品質の倍率**になります（×0.55〜×1.10）
- 40点未満だと「しくじり」がひとつ増え、検品で取り返せます
- **家具ごとに自己ベストが図鑑に残ります**（「もう一度作って100点を出したい」）
- 集中力が切れた状態で挑むと腕前が15%落ちます
- 「ふつうに作る」でとばすこともできます。腕前は並（×0.83）どまりで、時間が2時間よけいにかかります

工房紹介には**腕まえ**が★で出ます。研磨は得意だけど彫刻は苦手、といったあなた自身の職人像が、遊ぶうちに形になります。

## 品質と値段 ── 判断で天井を決め、腕で届く高さが決まる

最終的な品質は、2つの層の掛け算で決まります。

```
最終品質 ＝ 土台（通常工程の判断の積み上げ） × 腕前（山場のミニゲームの出来）
```

**土台**は素材50点からスタートし、設備・設計・素材・仕上げ・工程ごとの判断で積み上がります（最大100）。
**腕前**は山場のミニゲームの点そのもの。0点なら **×0.55**、100点なら **×1.10**。

| 土台＼山場 | 0点 | 30点 | 50点 | 70点 | 100点 |
|---|---|---|---|---|---|
| 65（準備が甘い） | 36 C | 46 C | 54 C | 61 B | 72 B |
| 80 | 44 C | 57 C | 66 B | 75 A | 88 A |
| 92 | 51 C | 66 B | 76 A | 86 A | **100 S** |
| 100（準備は完璧） | 55 C | 72 B | 83 A | **94 S** | **100 S** |

**準備が完璧でも、山場でしくじればCランクまで落ちます。** 逆に準備が甘ければ、満点を取ってもBどまり。片方だけでは良い家具になりません。

| ランク | 点数 | 値段 |
|---|---|---|
| S | 90点以上 | ×1.5 |
| A | 75点以上 | ×1.2 |
| B | 60点以上 | ×1.0 |
| C | 60点未満 | ×0.75 |

さらに **納期内なら+10%、遅れると−20%**。設計・素材・仕上げ・設備の倍率も掛かります。

## 展示と来館者

完成した家具は「納品する（すぐお金）」か「展示する（毎日の収入）」を選べます。

展示すると翌日から来館者が来て、売店収入が入ります。展示枠は最初2つ。設備をそろえると最大14枠まで増えます。

**セットボーナス7種**（組み合わせて重ねがけできます）
- アンティーク仕上げ2点以上 … +20%
- 小さな家具（ドール家具）2点以上 … +15%
- 童話を持つ家具3点以上 … +20%
- 漆黒か金箔の仕上げ3点以上 … +25%
- ローズウッドか黒檀3点以上 … +30%
- Sランク3点以上 … +35%
- 序章・第二章・第三章の家具を1点ずつ … +40%

**来館者6人**（伯爵・老婦人・若い画家・新婚夫婦・学者・近所の子）が展示を見てひとこと言っていきます。3割の確率で昔の職人の仕事について話し、それが隠し家具のヒントになります。

## 物語 ── いろいろな童話

家具をはじめて完成させると、その家具の短い物語が読めるようになります。

さらに12の家具からは、**やぶれた童話のページ**が1枚ずつ出てきます。森の切り株、白つめ草の野原、あけてはいけない引き出し、炉ばたの取り引き、鏡よ鏡、星の銀貨、いばらひめ、ガラスのくつ、まめの木、月をぬすんだ四人、空とぶトランク、星をかぞえた人 ── ばらばらの童話のはずなのに、どのページにも、この工房でこしらえた家具が置かれています。

そのうち5ページには、**作り方**がまぎれこんでいます。

> 「野原じゅうの白つめ草をさがしても、四つ葉は見つかりません。娘はあきらめて、**オーク**の木陰のカウチに寝ころびました。飾りけのない、**いちばん素直な形**のカウチです。**塗りはかけられていません**」

読めば作れる。つまり**童話そのものが攻略情報**になっています。

12ページそろうと、まっさらな13枚目 ──「最後のページ」が出てきます。

## 技術メモ

- `game/index.html` の1ファイルだけで動きます（HTML/CSS/JavaScript、約2,600行）
- 外部ライブラリなし・通信なし・サーバー不要
- イラストはすべてSVG（画像ファイルを持たないので軽い）
- 進行状況はブラウザのlocalStorageに自動保存。遊ぶ人ごとに個別に残ります
- 家具データは配列に分離してあり、1件足すだけで図鑑・設計図・物語がすべて自動で増えます
- 家具データに `photo` 欄を用意済み（将来、実物の写真を図鑑に載せられるようにするため）

**公開するには**
リポジトリの Settings → Pages → Branch を `main` にすると、
`https://kijibukobo.github.io/-/game/` で誰でも遊べるようになります。
アカウント不要・無料・人数制限なし。スマホのホーム画面に追加すればアプリのように起動します。
