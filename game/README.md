# 松永工房クラフトストーリー
### 〜小さな家具と、いろいろな童話〜

スマホのブラウザで遊べる、家具づくりのコレクションゲームです。
プレイヤーは有限会社松永工房の新人職人。**家具図鑑をぜんぶ埋めること**が目的です。

HTML1ファイルだけでできています。外部ライブラリなし、通信なし、インストール不要。

有限会社松永工房のシリーズです。ゲームの中にも、この3つが出てきます。

## 章 ── ゲームの背骨

家具43種は**3つの章**に分かれています。次の章は「前の章の家具を◯台、**会心**に仕上げる」で開きます。

> **会心の一台 ＝ Aランク以上を、納期内に仕上げたもの**

| 章 | 家具 | 開く条件 |
|---|---|---|
| 序章　工房の定番 | 14種 | 最初から |
| 第二章　物語の家具 | 15種 | 序章を**会心で5台** |
| 第三章　常識を超えた家具 | 14種 | 第二章を**会心で6台** |

ただ作れば進むのではなく、**よく作らないと進みません**。ここではじめて「品質を上げる理由」と「納期を守る理由」が生まれます。

章が開くと、**素材・設計・仕上げも増えます**。

## どう作るかを決める

制作前に3つ選びます。この組み合わせで品質・人気・値段が変わります。

**設計**
- クラシック … 品質+5・人気+5
- 豪華 … 人気+10・値段+20%（木材を1本多く使う）
- 小型 … 人気+5・値段−10%

**素材（木材12種）**
- 安い木は品質が下がるかわりに値段も下がります。高い木はその逆。
- 章が進むと、銘木が仕入れに並びます。

**仕上げ**
- アンティーク … 人気+10
- ナチュラル … 品質+5
- 漆黒 … 人気+5・値段+15%
- 柿渋（第二章）… 品質+8・人気+3・値段+5%
- 金箔（第三章）… 人気+20・値段+40%

## 制作中の判断

ここがゲームの中心です。工程ごとに3つの手から選びます。

**工程によって選べる手が変わります**（8種類）

| 工程 | 選べる手 |
|---|---|
| 木取り | 木目を読む／素直に取る／歩留まり優先 |
| 組立 | 仕口を締める／手順どおり／早く組む |
| 研磨 | 番手を上げる／ひととおり／ざっと当てる |
| 彫刻 | 彫り込む／控えめに／型どおり |
| 張り | しわなく張る／ふつうに張る／留めるだけ |
| 金具 | 面を揃える／取り付ける／手早く留める |
| 塗装 | 重ね塗り／一度塗り／乾かし急ぎ |
| 検品 | 隅々まで／ざっと見る／省く |

**集中力（1日100）**
ていねいな手ほど集中力を食います（30前後）。尽きると、ていねいな手が選べなくなります。「🌙 今日はここまで」で回復できますが、その日の残り時間は納期から引かれます。
→ **全部ていねいには作れません。どの工程に力を注ぐかを選びます。**

**山場工程（🔥）**
家具ごとに1工程だけ、品質の増減が2倍になります。最初はどこか分かりません。1台作ると教えてもらえて、次から図鑑にも記録されます。
→ **遊ぶほど賢くなります。**

**しくじりと修復**
急いだ手はときどき失敗して品質が下がります。最後の検品で「隅々まで」を選ぶと、傷をひとつ見つけて直せます。
→ **失敗しても取り返せます。**

## 職人アクション ── 山場は自分の手で作る（ミニゲーム10種）

山場の工程だけは、選択肢ではなく**画面を指で操作して**作ります。

10種あって、**どれも単体のゲームとして組んであります**。共通の決まりは3つ。

- **3つの波**がある。進むほど速く、狭く、多くなる
- **連続成功**が伸びるほど点が上がる
- しくじっても終わらない。ただし**1回につき3点引かれる**

### 点の付け方

| | 配分 | |
|---|---|---|
| 命中 | 72点 | 当てたかどうか |
| **決まりぐあい** | **10点** | そのうち、どれだけ**ど真ん中**で決めたか |
| 連続 | 18点 | いちばん長く続いた数 |
| しくじり | −3点／回 | |

**ぎりぎり入れ続けると90点、ど真ん中でそろえると100点。**

満点として数えます。

## 品質と値段 ── 判断で天井を決め、腕で届く高さが決まる

最終的な品質は、2つの層の掛け算で決まります。

```
最終品質 ＝ 土台（通常工程の判断の積み上げ） × 腕前（山場のミニゲームの出来）
```

**土台**は素材50点からスタートし、設備・設計・素材・仕上げ・工程ごとの判断で積み上がります（最大100）。
**腕前**は山場のミニゲームの点そのもの。0点なら **×0.55**、100点なら **×1.10**。

| 土台＼山場 | 0点 | 30点 | 50点 | 70点 | 100点 |
|---|---|---|---|---|---|
| 65（準備が甘い） | 36 C | 46 C | 54 C | 61 B | 72 B |
| 80 | 44 C | 57 C | 66 B | 75 A | 88 A |
| 92 | 51 C | 66 B | 76 A | 86 A | **100 S** |
| 100（準備は完璧） | 55 C | 72 B | 83 A | **94 S** | **100 S** |

**準備が完璧でも、山場でしくじればCランクまで落ちます。** 逆に準備が甘ければ、満点を取ってもBどまり。片方だけでは良い家具になりません。

| ランク | 点数 | 値段 |
|---|---|---|
| S | 90点以上 | ×1.5 |
| A | 75点以上 | ×1.2 |
| B | 60点以上 | ×1.0 |
| C | 60点未満 | ×0.75 |

さらに **納期内なら+10%、遅れると−20%**。設計・素材・仕上げ・設備の倍率も掛かります。

## 🏡 ドールハウス（飾り部屋）

フッターの **🏡 お部屋** から開きます。**作った家具を並べて飾る場所**です。

家具の絵は、図鑑と同じ**実物写真**をそのまま重ねています。写真61枚はすべて
背景が抜けてあるので、新しい絵を描かずに置けています。

### できること

| | |
|---|---|
| **置く** | 下の棚から選ぶと、床の上に出ます。**図鑑で一台でも仕上げた家具だけ**が棚に並びます |
| **動かす** | 指でつまんで、どこへでも。壁に掛けたいものは上へ |
| **大きさ** | ＋ － のほか、**二本指でひろげても**変わります |
| **左右を返す** | ⇄。椅子を向かい合わせにしたいときに |
| **前後** | 「手前へ」「奥へ」。たんすの前に椅子、など |
| **はずす** | 一台ずつ。「この部屋を片づける」でまとめて |

同じ家具を何台でも置けます。ひと部屋 **24台**まで。

### 部屋は5つ

| | |
|---|---|
| **本物のお部屋** | **松永工房の実物のドールハウスの写真。**空のまま正面から撮ったもの |
| 板張りの部屋／屋根裏／温室／夜の窓辺 | SVG で描いた絵の部屋 |

**部屋ごとに別の並べ方を覚えます。**部屋を変えても、前の部屋はそのまま残ります。

部屋を足すときは `ROOMS` に1行足すだけです。

```js
{ id: "petit", name: "本物のお部屋", ar: "1100/561",
  floor: 0.86, dh: 0.30, img: "petit" }
```

| | |
|---|---|
| `ar` | 縦横比。舞台の形をこれに合わせます（部屋ごとにちがってよい） |
| `floor` | 床の高さ。置いたときの足もとの既定値 |
| `dh` | 置いたときの大きさ（120mm の家具を基準に） |
| `img` | 写真の部屋なら `ROOM_ART` のキー。無ければ `svg` の絵の部屋 |

写真は市松（透過）のふちを落として長辺1100pxのWebPにしてあります。**33KB**です。

どの部屋を見ているかは **id** で覚えています（`state.room.bg`）。
並べかえても足しても、食いちがいません。

### 置いたときの大きさは、実寸から決まる

家具の説明文には実寸が入っているものがあります（例「（95×35×120mm）」）。
その**高さを読んで、120mm を基準に**部屋の `dh` へ掛けています。

おかげで、**たんすと小物入れを置いただけで、正しい大小になります。**
150mmの姿見は 0.30×150/120＝0.375、55mmのティーテーブルは 0.138。

寸法の書いていない家具（46種のうち15種）は **90mm 相当**で出ます。椅子やスツールが
多いのでそのあたりが無難、というだけの数字です。**説明文に「（◯×◯×◯mm）」を
足せば、そちらが使われます。**コードは触らなくてかまいません。

実寸がまだ入っていないのは次の15種です。

小さなスツール／帽子箱スタンド／アーチ背のセティ／礼拝堂のベンチ／
まるいチェスト／空色のアームチェア／鳥かごスタンド／オーバル鏡のドレッサー／
ジュエリーチェスト／街灯のランプ／キュリオケース／プティワードローブ／
プティ・ローズソファ／プティ・パウダーテーブル／プティ・ローズチェア

### どの家具をさわったか

写真は四角いですが、家具は四角くありません。四角で当てると、
**前にある家具の「透けている角」に取られて、うしろの家具をつかめなく**なります。

そこで、押した所の**写真が透けていないかどうか**で見ています。透け具合は
写真ごとに一度だけ調べて覚えます（1画素1バイト）。指は太いので、
押した所のまわり ±7px も見ます。

どの絵にも当たらなかったときは、いちばん手前の家具を返します。
椅子の脚のあいだのような「すき間」をつまんだ場合です。うしろに絵がある所は
先に拾われているので、取りちがえません。

canvas が読めない browser では、これまでどおり四角で当たります。

### 置き場（`state.room`）

```js
room: {
  bg: "petit",           // いま見ている部屋の id
  sets: {                // 部屋ごとの並べ方
    petit: [ { id:"stool", x:.5, y:.86, h:.225, fl:1 }, … ]
  }
}
```

`x` `y` `h` は部屋の幅・高さに対する**割合**です。画面の大きさが変わっても
崩れません。`y` は足もとの高さ、`fl` は左右の反転（1 か -1）。
配列の並びがそのまま前後で、**うしろの要素が手前**に出ます。

セーブに入りますが、位置の数だけなので 4部屋ぜんぶ埋めても数KBです。

## 🧸 うちの子（お人形の取りこみ）

棚のいちばん後ろの **🧸 うちの子をふやす** から開きます。
お人形の写真を取りこむと、**家具とまったく同じように**部屋に立たせられます。
動かす・大きさを変える・左右を返す・前後を入れかえる、ぜんぶ同じです。

### セーブとは別の置き場

写真は大きいので、**ゲームのセーブとは別の `localStorage` キー**に入れています。

| | |
|---|---|
| `matsunaga-craft-story-v1` | ゲームのセーブ。写真は一切入りません |
| `matsunaga-craft-story-dolls-v1` | うちの子の写真 |

写真がいっぱいで書けなくても、`setItem` が失敗するだけで**前の値はそのまま残ります。**
職人の記録には指一本ふれません。失敗したときは一覧を元にもどして、
「入れる場所がいっぱいじゃ」と伝えます。

**8人まで。**長辺420px、WebP（画質82）で、ひとり40〜70KBほどです。

### 切り抜きのやりかた

**すでに切り抜いてある透過PNGが、いちばんきれいです。**
透けている画素が4%を超えていれば「もう切り抜いてある」と見なして、
こちらでは何もしません。つまみも出しません。

- iPhone … 写真を長押しして「切り抜き」
- Android … Google フォトの切り抜き

ふつうの写真は、**ふちから似た色をたどって**背景を抜きます（`dollMask`）。
ふちの色は四辺の**中央値**。まんなかに同じ色があっても、
**ふちからつながっていなければ消えません。**

### 抜き具合は、こちらで見つくろう

ゆるめていくと、はじめは背景だけが消えていき、消える量ののびはほとんど止まります。
そのうちお人形まで食いはじめ、そこで**のびが「どん」と跳ねます。**その手前で止めます。

```
tol      8     12    16    20    26    32    40 ←ここで跳ねた
消えた量 .713  .714  .715  .716  .717  .718  .757
のび          .001  .001  .001  .001  .001  .038
```

跳ねたかどうかは、**ひとつ前ののびとくらべて**見ます（`d > 0.02 && d > prevD * 4`）。
もとからまだらな背景だと、のびはずっと大きいままなので、
「大きい」ではなく「**急に大きくなった**」で見るのが要ります。

これがないと、**白い背景に色の淡い子を置いたとき、顔だけが消えます。**
実際そうなりました。

### 直す手だて

| | |
|---|---|
| **つまみ** | 自動が気に入らなければ、手で動かせます |
| **🧽 消しゴム** | 消しのこりをなぞって消します |
| **やり直す** | 写真のところからやり直し。消したぶんも元にもどります |

消しゴムで消した所は、**つまみを動かしても残ります**（`erased` に覚えてある）。

### 部屋に置いたとき

持ち物に `k: "d"` が付きます。付いていなければ家具です。
**古いセーブの持ち物には `k` が無いので、そのまま家具として読めます。**移行は要りません。

```js
{ k:"d", id:"d1q2w3e", x:.46, y:.86, h:.30, fl:1 }
```

背たけの既定は **120mm 相当**。家具と同じものさしなので、
置いただけで家具との大小が合います。

お帰しになったうちの子は、部屋からも静かに出ていきます。

## 📷 撮影と 🖼 写真棚

飾った部屋を一枚の絵にして、しまっておけます。部屋の下の **📷 撮る** です。

### 見えているとおりに撮る

画面に出ている `<img>` を、そのまま canvas に写しています。位置も大きさも、
**画面から測った実寸をそのまま**使うので、プレビューと食いちがいません。

```js
const r  = el.getBoundingClientRect();
const k  = W / stage.getBoundingClientRect().width;   // 画面 → 写真の縮尺
g.filter = el.style.filter || "none";                 // 色ちがいの家具も、影も
```

`g.filter` に要素の `filter` をそのまま渡しているので、**秘伝の色ちがいの家具も、
落ちている影も、見えているとおりに写ります。**

| | |
|---|---|
| 写真の部屋 | 背景の `<img>` をそのまま敷く |
| 絵の部屋 | SVG を `data:image/svg+xml,…` にしていったん絵にしてから敷く |

横900px、部屋の縦横比のまま。WebP（画質82）で一枚60〜150KBほどです。

### 落款

右下に小さく `㈲松永工房　2026.10.14`。**写真棚のチェックで外せます。**

写真はお人形のためのものなので、ひかえめにしてあります
（はじめは工房名とゲーム名を両方入れていましたが、幅を取りすぎました）。

### 置き場は、これも別

| | |
|---|---|
| `matsunaga-craft-story-v1` | ゲームのセーブ |
| `matsunaga-craft-story-dolls-v1` | うちの子 |
| `matsunaga-craft-story-album-v1` | 写真棚 |

**12枚まで。**入りきらないときは一覧を元にもどして、その場で伝えます。
職人の記録には、やはり指一本ふれません。

### 端末にしまう

写真をおして大きくし、**⬇ 保存する**。`data:` のままでは落ちない browser が
あるので、いったん blob にしてから渡しています。

**ファイル名は英数字だけ**（`matsunaga-kobo-20261014-p….webp`）。
日本語のファイル名にしていたら、Chromium が `download` の指定ごと捨てて
`download` という名前で落ちてきました。端末によっては文字化けもします。

うまく落ちないときのために、大きく見ている画面には本物の `<img>` が出ています。
**長押しで保存**できます。

完成した家具は「納品する（すぐお金）」か「展示する（毎日の収入）」を選べます。

## 🎀 工房の催し（合言葉）

### いま入っている催し

|---|---|---|
| 合言葉つき | `https://kijibukobo.github.io/-/game/?k=neko` | 合言葉の欄に**自動で入った状態**で開く。会場で文字を打たなくてよい |

すでに遊んでいる人が合言葉つきのQRを読むと、その場で受けとって、あの日のページが開きます。

### 催しを足すには

`index.html` の **`EVENTS`** に1行足すだけです。

```js
{
  id: "dp54",                 // セーブに残る印。一度配ったら変えないこと
  key: "petit",               // QRカードの ?k= に入れる短い印（打ちこんでも通る）
  code: "ねこあし",            // 口で伝える合言葉
  title: "ドールズパーティー54",
  days: ["2026-11-30"],       // この日だけ。空なら、いつでも
  guests: true,               // 特別なお客さま5人
  gift: true,                 // あの日の小刀
  extra: ["rose_sofa"]        // その催しだけの設計図
}
```

合言葉の照合は **QRの印（`neko`）でも、合言葉（`ねこあし`）でも**通ります。

### 当日より前に、たしかめておくには（けいこ）

開催日を入れてあるので、ふだんは合言葉が通りません。当日より前に動きを見るには、
URLのうしろに **`?day=2026-11-08`** を付けてください。その日ということにして動きます。

```
https://kijibukobo.github.io/-/game/?k=neko&day=2026-11-08
```

> ページの中を読めば誰でも使えてしまうので、ほんとうの鍵は合言葉のほうです。
> （合言葉を知らない人は、`?day=` を付けても何も起きません）

日づけは**遊ぶ人の端末の時計**で見ています。日付が大きくずれている端末では通りません。
**翌日(9日)まで受けつけます。**10日になると受けつけません。
さらに延ばしたいときは `days` に日を足してください（何日でも並べられます）。

写真はすべて**背景を透過**にしてあります。ワードローブ・ダイニングテーブル・スツール・カウチ・密談椅子は、松永工房さんから切り抜き済みのものをいただきました。

残りの5点（姿見・ティーテーブル・チェア・ベンチ・ブックケース）は、白地の写真からこちらで抜いています。影は「色みのないうすい灰色」、家具は「色がついているか、うんと暗い」——この差で見分けました。

1. 白からうんと遠い画素を**芯**とし、いちばん大きなかたまりだけを残す
2. 芯からつながっている、そこそこ遠い画素まで**広げる**（影はこの線に届かない）
3. 家具の内側にできた**抜けをふさぐ**
4. **ふち**だけ、遠さに応じて半透明にしてなめらかにする

足すときは `index.html` の **`PETIT_ITEMS`** に1行足し、写真を `PHOTOS` に入れるだけです。`wide: true` を付けると横いっぱいになります。

## 自分の職人をつくる

はじめて開くと、自分の職人をこしらえるところから始まります。

絵は**松永工房さんが描いたもの**です。部品に分けて重ねています。

|---|---|---|
| 髪型 | **20** | ベリーショート／ショート／くせ毛風／サイドパート／マッシュ／おだんご／ミディアム／ロング／くるくる／おかっぱ・ポニーテール を2組 |
| 髪の色 | 6 | 黒・こげ茶・赤茶・金・白・あかね |
| 肌の色 | 4 | |
| 目 | **5** | 丸目／まるい目（閉じ）／たれ目／つり目／キラ目 |
| 口 | **5** | にっこり／あけ口／まっすぐ／ほっ／えがお |
| ひげ | 3 | くちひげ／あごひげ／ひげ |
| めがね | 3 | 丸メガネ／スクエア／ウェリントン |
| **ピアス** | 3 | スタッド／フープ／ドロップ |
| かぶりもの | **9** | ニット帽／サンタ帽／キャップ／ウサ耳／クマ／ネコ／ベレー帽／ストローハット／飛行帽 |

**480万通り**をこえる組み合わせがあります。

### どう組み立てているか

絵は 256×256 の同じ座標にそろえてあり、下から順に重ねるだけで合うようにしてあります。枠は「頭の広がり」に合わせてあるので、顔が小さく下に寄りません（そのぶん、ウサ耳だけは耳の先が切れます）。

1. **頭** ── 髪と顔がひとつづきの絵。これが土台
2. **目・口** ── 肌ごと四角で貼りかえるので、土台の目と口は隠れる
3. **ひげ → めがね → ピアス → かぶりもの** ── その上に重ねる

**髪の色と肌の色は、絵の明暗をそのままにして塗りかえています。**水彩のかすれや紙の目は消えません。塗りかえるのは髪（頭とひげ）と肌（頭と目と口の貼りかえぶん）だけで、帽子やめがねの色は動きません。

塗りかえの基準は、**その絵じたいの平均の明るさ**です。決まった値を基準にすると、髪より明るく描かれているひげのときに掛け算が振り切れて、白く飛んでしまいます。平均のところがちょうど選んだ色になり、そこから暗いほう・明るいほうへ伸びる帯にのせ替えています。

**ひげは、色を選んでいなくても髪に合わせます。**ひげの絵は髪より明るい茶色で描かれているので、そのままでは髪と色がそろいません。

絵は `AV_ART`（名前 →「左・上・WebP」）に入っています。部品を足すときは、絵を1枚入れて `AV_HAIR` などの一覧に1行足すだけです。**番号はセーブに残るので、途中に差しこまず、うしろに足してください。**

かぶりものを選ぶ列では被り物を外した見本を出すなど、**その部品を隠してしまうものは見本から外して**あります（`AV_HIDE`）。

名前をつけると、案内役のKoBoさんがその名前で呼んでくれます。

> 「石原 賢、この家具は『彫刻する』が山場じゃったな。覚えておくのじゃぞ」

顔と名前は、ヘッダーの顔をタップすればいつでも作り直せます。

**前の似顔絵で作った職人も、そのまま続けられます。**部品が入れかわったので、セーブの番号はいちばん近いものへ読みかえています（くるくる→くるくる、麦わら→ストローハット、など）。肌と髪の色はそのままです。

## 🧭 はじめの一台の案内

遊び方がわからない人のために、**最初の一台だけ**手順を教えます。
次に押すところが金色に光り、下の帯に「なぜそうするか」が出ます。

| 場面 | 言うこと |
|---|---|
| 設計図えらび | まずは設計図をえらぶのじゃ |
| 材料が足りない | 下の🧺仕入れで、木を一本買うのじゃ |
| 設計・木・仕上げ | 決まったら「制作をはじめる」じゃ |
| 工程 | ひとつずつ。ていねいにやるほど品質は上がるが、時間と集中力を食う |
| 山場 | 「腕を見せる」を押すと、おぬしの手で仕上げられる |
| 完成 | 納品すれば金に、展示すれば毎日お客が見にくる |

**いつでも「案内をやめる」で消せます。**工房の画面から呼びもどせます。
**一台できあがったら、案内は自動で終わります**（以後もう出ません）。

### どう決めているか

次に何をすべきかは、**画面に出ているもの**から決めています。
「いま何工程目か」「何台目か」といった中の事情は見ていません。

```js
const GUIDE_STEPS = [
  { sel: "#btn-deliver",              say: "…" },   // 納品のボタンがあれば、それ
  { sel: "#btn-action",               say: "…" },   // 山場のボタンがあれば、それ
  { sel: ".choice-btn:not([disabled])", say: "…" },
  …
];
```

上から順に見て、**最初に画面にあったもの**を案内します。
家具を足しても、工程を変えても、ミニゲームを入れ替えても、
案内のほうを直す必要はありません。

## 案内役・KoBoさん

緑のベレー帽に丸めがねの老紳士。工房の家具に惚れこんで、勝手に案内役をしています。

工程を選ぶたび、完成したとき、納品したとき、新しい設計図が解放されたときに声をかけてくれます。工程のあいまには「工房まめ知識」を披露します。

> 「木には『顔』があっての。板の木目を読んで向きを決めるだけで、家具の表情がまるで変わるんじゃ」

## 技術メモ

- `game/index.html` の1ファイルだけで動きます（HTML/CSS/JavaScript、約6,300行・約1.3MB）
- 外部ライブラリなし・通信なし・サーバー不要
- 家具のイラストはSVG。**実物の写真と職人の似顔絵は WebP**（データとして中に入っているので、
  やはり通信は起きません）
- 進行状況はブラウザのlocalStorageに自動保存。遊ぶ人ごとに個別に残ります
- セーブには版（`state.ver`）があり、古いデータは順に読みかえて引き継ぎます。
  **消さずに、必ず読みかえてください**
- 家具データは配列に分離してあり、1件足すだけで図鑑・設計図・物語がすべて自動で増えます
- 家具データの `photo` 欄に実物の写真が入ります（図鑑から本物のページへつながります）

**公開するには**
リポジトリの Settings → Pages → Branch を `main` にすると、
`https://kijibukobo.github.io/-/game/` で誰でも遊べるようになります。
アカウント不要・無料・人数制限なし。スマホのホーム画面に追加すればアプリのように起動します。
